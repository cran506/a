## 统一参数、数据与故障

参考仓库快照为 **bae77ed1fbfb6d9711a50e2e7a9bad437945e5bb**。独立实现统一四个物理状态 `[x,v,P1,P2]`，不把不同章节的旧轨迹混排。

共同教学参数：A1=0.002m²、A2=0.001m²、m=500kg、L=0.30m、两侧附加容积各0.00015m³、Ps=21MPa、Pr=0.10MPa、阀最大位移0.001m、死区±0.5V、Fs=800N、Fc=500N、vs=0.05m/s、粘性1000N·s/m、tanh尺度300。几何/阀参数是本综合工况公开选择，不冒充设备辨识结果。

合成真值：beta=1.10GPa、Ct=2.40e-12m³/(s·Pa)。DE在[0,1]²搜索，映射beta到0.5—1.8GPa、Ct到10^-12.5—10^-11。位移/两腔压力观测含20μm/20kPa高斯噪声及0.8%脉冲污染。因果滤波同样施加于观测和候选模拟输出，避免把滤波时延误辨为模量；留出激励不参与优化。

主对比：所有策略从40mm、零速、双腔0.1MPa开始，0.8s内走80mm，保持至1.2s，Ts=1ms。极限工况在0.50s同时突加5000N未知外载，并把有效体积模量整体乘0.5。实际对象使用独立真值，模型辅助和MPC使用辨识值且不读取真实故障倍率。

低压采用Wood近似 `1/beta_mix=.999/beta_oil+.001/P`，故障倍率作用于整个beta_mix。Stribeck是连续滑动近似，未声称包含严格静摩擦粘住/释放；补油是连续性方程中的真实流量，没有裁剪压力或位移。该模型不是完整两相气穴模型。

## 控制器及公平性

- PID：增量式，Kp=250、Ki=150、Kd=1（误差单位m），不完全微分alpha=0.85，实际饱和输出记忆。
- 模型辅助：参考导数、外环位置/速度误差、逆动力学、液压力G/H反演、当前压差增益和死区逆。
- LTV-MPC：30步、3轮滚动局部QP，精确ZOH离散化当前仿射模型，显式保留偏置项；状态缩放为mm、m/s、MPa、MPa。
- 模型辅助和MPC各自使用同结构的8ms因果负载估计器，只读取当前压力和历史速度，不读取真实外载标签。PID不使用该模型估计器。结果代表不同控制器组合，不将优势单独归因于某一补偿项。
- 主对比采用理想完整状态反馈，带噪滤波仅属于辨识模块；未声称完成含ADC噪声和观察器的全链路硬件验证。

MPC优化有效开口w，约束|w|≤9.5V、|Delta w|≤1V、每轮计划变化≤2V；经死区逆后|u|≤10V，跨零时|Delta u|≤2V。两腔**预测上界**为19.5MPa，物理验收线21MPa。最小压力没有进入QP；低压/气穴风险单独记录，不能把防过压等同全域安全。

无可行解会终止并记录，不静默使用零动作。迭代上限候选仅在独立约束残差≤0.0002时作为明确记录的可行近似接收；一般解要求残差≤0.002。所有QP状态、原始残差及采样矩阵保存。Ts=1ms只是仿真采样周期；本机完整MPC计算未达到1ms硬实时。

## 指标与附加验证

- 全时程RMSE：0—1.2s，包括相同运动和保持段。
- 扰动MAE：`max |e|`，窗口0.50—0.65s；不是平均绝对误差。
- TV：实际电压u的总变差，包含死区逆跨零跳变。急停从其实际前一巡航电压起算。
- Pmax：双腔、全时程、64个RK4子步节点的最大值，再以独立Radau重放复核。节点监测不等于连续安全定理。

标称与复合扰动都比较PID/模型辅助/MPC；额外急停从80mm、0.7m/s及稳态平衡压力/电压开始，比较仅输入MPC与双腔限压MPC。该试验使压力约束真正活跃。模型辅助急停时局部逆增益非正，程序终止，报告没有补齐后半条曲线，也不把其短记录RMSE与完整记录直接排名。

报告保留以下未通过或未涵盖项：低压/气蚀、硬实时、模型辅助在极端急停中的逆模型有效性、实机精度、未建模阀动态，以及按本次范围暂缓的第八章。全部数据为本次工程运行所得，无预设“理想指标”或剪贴旧图。
