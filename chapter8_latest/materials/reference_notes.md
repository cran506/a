# 第八章课堂材料与实现映射

原始课件按字节保存在 `chap08-ppt.pdf`，`chap08.txt` 为供检索的文本提取。课件和用户粘贴的三个类是教学参考，运行入口及最终数值以实际代码、日志为准。

| 课件部分 | 代码 | 实现及必要修正 |
|---|---|---|
| 8.1、8.5 Gym 环境 | `hydraulic_env.py` | 保留连续动作及原始毫米奖励；使用环境 RNG 保证 reset(seed) 可复现；补充腔室容积、双压力、参考及历史输入所需观察量 |
| 8.2 SAC | `train_sac.py` | 真实 SB3 actor/双 critic/温度优化；真实孪生交互；tanh 修正动作熵与电压熵分别记录，不合成训练曲线 |
| 8.3 HOCBF | `safety_filter.py`、`safety_experiment.py` | 明确采用参考公式对应的二阶约化对象；使用可分解的递归增益与整个 ZOH 区间的可行约束；不可行时明确报错 |
| 8.4 故障随机化 | `hydraulic_env.py`、`evaluation.py` | 标称随机参数外增加公开的负载与体积模量事件增强；四组共享初态与故障；仿真测试不冒充真实试验台迁移 |
| 8.6 剪枝/量化 | `edge_exporter.py`、`edge_inference.py` | 排序确定真实剪枝数；保持仿射零点；执行整数点积和重缩放，而非只把 INT8 权重反量化后用浮点推理 |

课件提供的是趋势与教学标度。仅将体积模量减半，不会把液压稳态流量直接减半；本项目由负载改变实际阀口压差产生稳态电压变化。未将示例的 9.10 V、−14.1 mm/s、0.08 s、0.06 ms 等值赋入结果信号。

归一化动作空间的微分熵上限为 ln(2)，电压空间的上限为 ln(20)。因此约 2.8 nat 只能在明确电压单位等定义下讨论。当前确定性四策略评估不含额外随机 dither；滑动摩擦模型也不单独验证静止粘住/释放机理。

参考 HOCBF 的二阶式针对 `x'=v, v'=1850u−14v`。它不能直接证明具有两个独立压力状态的四阶液压对象安全；本项目把该演示范围直接写在图题与报告内。严格真机 HOCBF、低速粘滑专项、ONNX/MCU 固件及真机少样本微调需要另行验证，未混入本次仿真结果。
