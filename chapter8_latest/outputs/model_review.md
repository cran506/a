# 第八章实现独立审查

本审查针对 `hydraulic_twin.py`、`native_twin.cpp`、`hydraulic_env.py`、`train_sac.py`、`evaluation.py`、`safety_filter.py`、`safety_experiment.py` 和边缘导出模块的实际实现。训练最终步数、闭环优劣和图形趋势必须以训练结束后产生的原始 CSV/JSON 为准；以下核验不代替训练结果。

## 物理模型和数值积分

- 四个积分状态为 SI 单位的 `[x,v,P1,P2]`，真实可变腔室容积、带方向的孔口压差、Stribeck 滑动摩擦、内泄漏、补油和泄压均出现在 RHS 中。积分器不通过裁剪位置、速度或压力拼接响应。
- 本章采用公开紧凑缸参数，不是此前大面积缸辨识参数。计算得到 50 mm/s 空载稳态电压 **3.509864 V**、5000 N 带载稳态电压 **6.677556 V**。固定空载电压而施加故障后，实际速度降至约 **24.70 mm/s**。这些数值来自流量/力平衡，没有将参考曲线回填为模型输出。
- 体积模量减半改变压力动态，不直接把稳态流量减半。负载引起的驱动腔压力上升与压差减小，才是稳态所需电压提高的原因。
- 独立 Radau 对相同输入跳变和故障事件逐段积分，与 native RK4 的 150 ms 轨迹比较：8 子步最大绝对误差为位移约 `9.03e-10 m`、速度约 `2.02e-7 m/s`、P1 约 `70.74 Pa`；16/32 子步误差继续减小。完整测量值见 `physics_validation.json`。
- 修复了零速带载稳态原本遗漏泄漏的问题。当前静止 +5000 N 平衡由逆解得到约 0.529838 V，力与流量残差均通过验证。此修复不改变正速训练路径。
- 修复配置参数优先级：JSON 默认值 < `config` 映射 < 显式非 None 构造参数。`reset()` 默认初位移/速度读取配置。默认课堂参数与正在进行的训练行为保持相同。

## 环境、单位和因果性

观察向量顺序为位置误差(mm)、速度误差(mm/s)、加速度误差(mm/s²)、P1(MPa)、P2(MPa)、绝对位置(mm)、参考速度(mm/s)、参考加速度(mm/s²)、上一实际电压(V)、供油压力(MPa)。它补上腔室容积和奖励所需的历史输入；未知随机质量、摩擦和事件参数仍是隐藏上下文，不能据此宣称任意参数未知工况已成为完全可观测 MDP。

`obs_mean`/`obs_std` 为公开固定工程尺度，不是从训练样本拟合的统计均值/方差，因此不保证观察样本严格零均值单位方差。采用这种尺度缩放并不影响其用于神经网络输入的有效性。

每步奖励先在原始物理单位下计算：

`-100*e_mm² - 0.1*u_V² - (u_V-u_prev_V)² + 2*I(|e_mm|<0.2)`。

物理包络失败时额外扣 500 并终止，这个终止惩罚超出基础公式，代码和报告应明确记录。`Monitor` 包在 `RewardScale` 内侧，因此记录未缩放的真实奖励；优化器接收 0.01 倍奖励，属于公开数值设计。该缩放也改变奖励相对自动熵温度的数值标度。

训练 CSV 的 `reward_mean` 是“每个已结束回合总回报/该回合真实长度，再对最近 30 回合平均”，**不是平均回合总回报**。报告或图例应使用“回合平均每步奖励”并保留真实量级。

步进先按当前区间事件状态积分，再更新时间和上一输入。故障恰在采样边界发生时，下一个观察包含该时刻右极限的理想瞬时加速度，而压力/速度仍连续。这是一种无噪声、无时延加速度传感器假设；它让策略能够立即感知负载，但没有向策略提供未来状态。真实设备中的传感器延迟、差分加速度噪声尚未验证。

Gymnasium `check_env` 通过（仅产生无限 Box 范围提示）；两个独立环境相同 reset seed、相同动作序列的 200 步观察、奖励、终止状态完全一致，最大观察差为零。随机采样使用 `self.np_random`，不存在全局 NumPy RNG 破坏 reset seed 的问题。

## SAC、熵和域随机化

- 训练调用真实 SB3 SAC 和真实孪生交互，没有用解析曲线代替策略或日志。最终实际步数须与 `training_metadata.json` 及 CSV 末行核对。
- 归一化动作 `a∈[-1,1]` 经 `u=10a` 映射为电压。`actor.action_log_prob` 包含 tanh 变换的雅可比修正，因此 `H_V=H_a+ln(10)` 换算成立。归一化动作微分熵上限为 ln(2)，不能将课件 2.8 nat 当成该空间上的熵。
- `.35-ln(10)` 被明确配置为目标熵，晚期约 0.35 nat 的电压熵属于目标设计，不能描述成事先没有指定而必然涌现的常数。曲线是 replay 状态上的 Monte Carlo 策略熵估计；随机预热动作并非由 actor 生成。
- 质量 ±20%、基准体积模量 0.6–1.4 GPa、摩擦 ±30% 域随机化之外，还使用随机负载及 0.5–1 倍刚度故障增强。5000 N/50% 的评估故障因此属于训练包络覆盖下的仿真鲁棒性验证，不能称作完全未见工况的 OOD 外推。
- 确定性评估输出 actor 均值，没有随机探索噪声。图中即使有残余纹波，也不能直接称作“非零熵产生的 dither”。
- 训练初始化为 35–65 mm/s 巡航，摩擦使用连续滑动近似而非静摩擦粘住/释放模型。因此当前四图不能单独证明低速死区概率渗透、静摩擦突破或爬行消除；若要对此作物理验证，还需要专门的低速/起动工况及集合值摩擦模型。

## HOCBF 安全范围

安全演示明确针对 `x'=v, v'=1850u-14v` 的二阶约化模型；与 SAC 所用四状态压力模型分开。系数使用 `kappa1=kappa2=24`，从而 alpha 和为 48、积为 576。原示例的 580 无法分解为这组正实一阶增益。

滤波器是标量凸 QP 的精确区间投影，校验输入幅值与整个 ZOH 区间上的屏障不等式；初态须同时满足距离及高阶 psi1 条件。不可行状态抛出异常，而不是任意返回一个被标记为安全的值。128 个随机可行情形经独立 DOP853 检查通过。实际最低干预电压约 −0.301 V，1 s 终位移约 98.79999984 mm；未保护轨迹首次撞到 100 mm 时刻为 0.131286 s。参考图中的 −3.1 V、0.105 s 并不是当前约化模型的实际计算结果。

此证书不能直接转移到四状态液压模型或带阀动态模型，更不能称作未知外扰下的真机绝对安全保证。

## 公平比较和边缘导出

- 四组策略共用相同液压 RHS、初态、Ts 和 .5 s 复合故障。全局 .4 s 从巡航平衡初态开始；没有声称实际模拟了 .0–.4 s 起动过程。
- 传统 PID 只用位置/速度误差；标称前馈为无载稳态逆解，明确不使用负载适应。它保持无载电压而产生偏差，与课件“已部分适应但不足”的 5.35 V 基线定义不同；两者不可逐点等同。
- 速度误差在输出 CSV 中为 `v_actual-v_ref`，环境用于反馈的速度误差是反号 `v_ref-v_actual`；各自用途一致，图表必须使用输出定义。
- 真实 70% 权重掩码剪枝、固定掩码蒸馏、INT8 权重/激活与 INT32 点积、INT64 重缩放均有独立实现；输入量化与末端 tanh 保留浮点。
- INT8 使用自身闭环状态重新求动作，不替换成 FP32 轨迹。一次 FP32 commissioning 轨迹被明确纳入校准，因此它不是完全留出评估。训练 replay 中校准和验证观察行不重叠，但来自相同训练分布，不代表独立真机数据。
- 文件体积和 CPU 中位/P95 耗时由实际工件/重复测量得到，不能套用课件 92.5% 压缩或 0.06 ms 的数字。当前 NumPy 整数原型不等于无依赖 C 固件，也不包含 ONNX/MCU 硬实时认证。

## PPT 覆盖与剩余边界

课堂核心四模块均有实现：真实 SAC 训练/熵统计、约化模型 HOCBF 最小干预、四组同对象复合故障验证、剪枝与真实整数推理。课件的真机小样本微调、MCU 静态 C 部署与严格静摩擦消爬行属于尚未进行的硬件/专门工况验证，应在交付中保留范围说明。课后作业 8-4 的四种随机化宽度对比属于另一个作业，不应混充本次课堂四组策略实验。

后续结果验收应查看实际 1M 日志是否完成、四组 CSV 是否覆盖全时段、SAC 的恢复与电压曲线是否达到预期趋势，以及 INT8 闭环是否仍保持足够精度。若未达到，须保留原始结果并改进训练/压缩，不能据此审查文档宣称性能已经达标。
