【实验内容与学习指引】
本程序在 1 kHz 采样频率 (Ts = 1 ms) 与 12 位位移传感器量化采样环境下，驱动 500 kg 重载液压机滑块
按 S 型规划轨迹在 1.0 s 内完成 100 mm 定位任务，并在 [0.35 s, 0.70 s] 区间模拟冲压工件接触负载。
程序通过以下三组平行对比实验，验证数字 PID 的工程改造效果及其面对非线性时变液压系统时的性能边界：

  1. 情形 A [保守增益 PID + 不完全微分滤波 (Kp = 3.8, alpha = 0.85)]：
     - 物理表现：空载加速与 0.70 s 卸载后均平稳收敛、无振荡；但在 [0.35 s, 0.70 s] 重载冲压区内，
                 由于负载压力升高导致阀口流量增益 Kq 大幅衰减，环路动刚度不足，产生显著的动态跟踪滞后。
  2. 情形 B [激进增益 PID + 不完全微分滤波 (Kp = 16.0, alpha = 0.85)]：
     - 物理表现：在重载冲压区内凭借高控制器增益补偿了物理增益衰减，动刚度高、跟踪滞后小；
                 但在 t = 0.70 s 卸载瞬间，物理流量增益 Kq 骤然回升至空载峰值，过高的环路总增益
                 耗尽系统相位裕度，诱发围绕参考轨迹的持续极限环振荡。
  3. 对比组 [保守增益 PID + 无微分滤波 (Kp = 3.8, alpha = 0.00)]：
     - 物理表现：展示 12 位 ADC 的最小量化台阶 (0.073 mm) 经 1/Ts (1000 倍) 后向差分放大后，
                 在伺服阀控制电压中引发的高频噪声毛刺，验证一阶不完全微分滤波器的工程必要性。

# 模块二：工程级增量式数字 PID 控制器 (对应教材 5.1.2 节 & 5.2 节)
# ==============================================================================
class DigitalPID:
    """
    集成不完全微分滤波与输出硬限幅抗饱和机制的增量式数字 PID 控制器 (对应教材 Listing 5.1)
    
    核心离散递推公式:
      1. 比例控制增量 (教材式 5.2 第一项):
         delta_u_p[k] = Kp * (e[k] - e[k-1])
      2. 积分控制增量 (教材式 5.2 第二项):
         delta_u_i[k] = Ki * e[k] * Ts
      3. 不完全微分一阶低通滤波 (教材 5.2.1 节式 5.3 ~ 5.4，“先滤波、后增量”原则):
         D_filt[k] = alpha * D_filt[k-1] + (1 - alpha) * (Kd / Ts) * (e[k] - e[k-1])
         delta_u_d[k] = D_filt[k] - D_filt[k-1]
      4. 控制量合成与硬限幅抗饱和更新 (教材 5.2.2 节式 5.5):
         u[k] = min(max(u[k-1] + delta_u_p[k] + delta_u_i[k] + delta_u_d[k], u_min), u_max)
    """
    def __init__(self, kp, ki, kd, ts, out_min=-10.0, out_max=10.0, alpha=0.85):
        """
        初始化增量式数字 PID 控制器
        :param kp:      比例增益 (以 cm 为误差基准单位，即 V/cm)
        :param ki:      积分增益 (V/(cm·s))
        :param kd:      微分增益 (V·s/cm)
        :param ts:      数字控制采样周期 Ts (s)
        :param out_min: 伺服放大器物理输出电压下限 (-10.0 V)
        :param out_max: 伺服放大器物理输出电压上限 (+10.0 V)
        :param alpha:   不完全微分滤波系数 [0, 1)；alpha=0 代表未加滤波的标准后向差分
        """
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.ts = ts
        self.out_min = out_min
        self.out_max = out_max
        self.alpha = alpha
        self.reset()

    def reset(self):
        """清空控制器内部历史状态记忆"""
        self.e_prev = 0.0       # 上一采样时刻位置偏差 e[k-1] (cm)
        self.d_filt_prev = 0.0  # 上一采样时刻滤波后微分项 D_filt[k-1] (V)
        self.u_prev = 0.0       # 上一采样时刻实际输出电压 u[k-1] (V)

    def update(self, target, feedback):
        """
        单步采样中断计算函数：根据参考位置与传感器反馈位置解算当前控制电压 u[k]
        :param target:   当前时刻参考位置指令 r[k] (m)
        :param feedback: 当前时刻传感器位置反馈 y[k] (m)
        :return:         限幅后的控制电压 u[k] (V)
        """
        # 将位置误差折算为厘米 (cm) 标度，使控制器增益处于工程直观调参区间
        e_k = (target - feedback) * 100.0
        
        # 1. 计算比例项增量与积分项增量 (在大偏差瞬态区适度削弱积分累积，防止退饱和反冲)
        delta_up = self.kp * (e_k - self.e_prev)
        int_factor = 1.0 if abs(e_k) < 0.15 else 0.05
        delta_ui = self.ki * e_k * self.ts * int_factor
        
        # 2. 计算不完全微分项及其增量 (对应教材式 5.3 & 5.4)
        # 当采样周期 Ts = 0.001 s 时，传感器 1 个 LSB 的量化跳变会被 1/Ts 放大 1000 倍；
        # 一阶低通滤波通过权重 (1 - alpha) 显著衰减高频量化尖峰。
        raw_diff = (self.kd / self.ts) * (e_k - self.e_prev)
        d_filt_k = self.alpha * self.d_filt_prev + (1.0 - self.alpha) * raw_diff
        delta_ud = d_filt_k - self.d_filt_prev
        
        # 3. 累加控制增量并执行硬限幅抗饱和 (对应教材式 5.5)
        # 截断后的 u_k 直接作为下一周期的历史状态 self.u_prev，防止控制器内部状态溢出物理边界
        delta_u = delta_up + delta_ui + delta_ud
        u_k = np.clip(self.u_prev + delta_u, self.out_min, self.out_max)
        
        # 4. 更新历史记忆状态
        self.e_prev = e_k
        self.d_filt_prev = d_filt_k
        self.u_prev = u_k
        
        return u_k

# 模块三：基于急动度 (Jerk) 限制的七段式 S 型轨迹规划器 (对应教材 5.3.1 节与图 5.1)
# ==============================================================================
def generate_scurve(dist=0.1, T_move=1.0, T_total=1.4, dt=0.001):
    """
    生成加速度连续、三阶导数 (急动度 Jerk) 有界的对称七段式 S 型参考轨迹 (对应教材 5.3.1 节)
    
    【轨迹规划物理机理】：
    若直接输入阶跃指令或梯形速度指令，加速度在变速拐点处的阶跃突变对应着驱动力的瞬时跳变，
    会在高压液压管路中诱发“水锤效应”压力冲击，并激发“液压弹簧-负载质量”构成的二阶固有共振模态 (omega_h)。
    S 型速度规划通过限制急动度 (Jerk)，使加速度呈连续梯形过渡，将指令信号的频域能量集中在低频段。
    
    :param dist:    目标定位行程 (m)，本案例为 0.1 m (100 mm)
    :param T_move:  S 型轨迹运动段时长 (s)，本案例为 1.0 s
    :param T_total: 包含到位保持段的总仿真时长 (s)，本案例为 1.4 s
    :param dt:      离散采样周期 Ts (s)
    :return:        时间序列 t_seq, 期望位置 r_pos, 期望速度 r_vel, 期望加速度 r_acc
    """
    steps = int(np.round(T_total / dt))
    t_seq = np.linspace(0.0, T_total, steps)
    
    # 七段式时间分配 (总运动时长 T_move = 1.0 s)：
    # 1.加加速段(0.10s) -> 2.匀加速段(0.15s) -> 3.减加速段(0.10s) -> 4.匀速段(0.30s)
    # -> 5.加减速段(0.10s) -> 6.匀减速段(0.15s) -> 7.减减速段(0.10s)
    t_j  = 0.10 * T_move
    t_ca = 0.15 * T_move
    t_a  = 2.0 * t_j + t_ca      # 加速区总时长 0.35 s
    t_cv = T_move - 2.0 * t_a    # 匀速巡航区总时长 0.30 s (0.35 s ~ 0.65 s)
    
    t1, t2, t3 = t_j, t_j + t_ca, t_a
    t4 = t_a + t_cv
    t5, t6, t7 = t4 + t_j, t4 + t_j + t_ca, T_move
    
    # 构建归一化急动度 (Jerk) 序列
    j_profile = np.zeros_like(t_seq)
    for i, t in enumerate(t_seq):
        if t < t1:   j_profile[i] = 1.0
        elif t < t2: j_profile[i] = 0.0
        elif t < t3: j_profile[i] = -1.0
        elif t < t4: j_profile[i] = 0.0
        elif t < t5: j_profile[i] = -1.0
        elif t < t6: j_profile[i] = 0.0
        elif t < t7: j_profile[i] = 1.0
        else:        j_profile[i] = 0.0  # t >= 1.0 s 进入目标位置保持段
            
    # 采用梯形积分法则逐级生成连续的加速度、速度与位置曲线
    r_acc = np.zeros_like(t_seq)
    r_vel = np.zeros_like(t_seq)
    r_pos = np.zeros_like(t_seq)
    
    for i in range(1, steps):
        r_acc[i] = r_acc[i-1] + 0.5 * (j_profile[i-1] + j_profile[i]) * dt
        r_vel[i] = r_vel[i-1] + 0.5 * (r_acc[i-1] + r_acc[i]) * dt
        r_pos[i] = r_pos[i-1] + 0.5 * (r_vel[i-1] + r_vel[i]) * dt
        
    # 按目标定位总行程 dist 精确缩放，并锁定末端保持段数值
    scale_factor = dist / r_pos[int(np.round(T_move / dt))]
    r_acc *= scale_factor
    r_vel *= scale_factor
    r_pos *= scale_factor
    
    hold_mask = t_seq >= T_move
    r_acc[hold_mask] = 0.0
    r_vel[hold_mask] = 0.0
    r_pos[hold_mask] = dist
    
    return t_seq, r_pos, r_vel, r_acc
