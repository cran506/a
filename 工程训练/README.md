# 工程训练｜音乐电路（X=1）

选题：设计一个音乐电路，并演奏一段音乐。基础难度系数0.75，三人小组A、B、C。

## 文件入口

- **专业工程训练任务书_音乐电路.docx / .pdf**：改编后的双页任务书，A4双面打印；第二页为15个工作日进度表、分工与签字栏。
- **个人任务书/**：A、B、C各自的双页任务书，突出本人独立承担的技术任务；小组版与个人版按教师要求选用，无需全部重复提交。
- **音乐电路_设计方案汇报.pptx / .pdf**：小组方案汇报，含完整原理图、关键局部放大图及逐页演讲备注。
- **汇报讲稿与使用说明.docx / .pdf**：逐页讲稿、A/B/C讲解分工及使用说明。
- **设计附件/**：A3原理图PDF、可编辑SVG、音符参数CSV、接口与软件设计说明、课程要求落实表。

## 方案范围和当前状态

STC89C52RC最小系统，12MHz晶振、12T时序；Timer2管理音高，Timer0形成1ms系统节拍。无源电磁蜂鸣器通过74HCT14与S8050驱动，一位共阳数码管显示当前简谱1—7；三按键实现播放/暂停、停止、重播。演奏《小星星》（42音符、48拍、120 BPM，约24秒）。

本次形成的是**设计方案与汇报材料**。参数表为理论计算，未提供实物或实测数据；采购、焊接、固件实现/编译下载、示波器测量和演示视频尚待完成。文档没有宣称硬件已经演奏成功，也没有伪造测试结果。

## 使用前补齐

1. 补实际小组编号、起止日期及师生签字；班级按课程材料写为智能制造2303班，使用前核对。
2. 汇报时间按教师群通知确认。课程PDF列11月10日（周二），群截图写周一上午，截图未给绝对日期，因此材料不擅自确定日期。
3. 本题基础系数为0.75；数码管和按键为设计配置，是否提高系数由教师认定。
4. 任务书优先打印PDF（A4、100%、长边翻转、双面）。编辑Word后重新核对两页分页；PPT使用前核对中文字体。PDF可用作投影备用。
5. 原始上传任务书为机械减速器模板。本次保留“题目—设计条件—注意事项—进度表—审核”用途，将机械参数替换为电子电路参数。
6. 最终答辩还需三份独立个人报告、完整程序、实物和配音演示视频；本包不冒充最终答辩全套。按实际小组编号整理U盘文件夹。
