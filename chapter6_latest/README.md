# 第六章模型辅助复合控制

结合第六章 PPT、Word 的模块三 `ModelAssistedController` 及已有液压数字孪生，比较纯 PID、标称前馈 + PID、完整压力自适应前馈三种课堂策略。默认交付一张四联图，展示全程真实误差、总控制电压、起动速度和负载切换速度。

## 运行

需要 Python 3.10 或更高版本，依赖 NumPy、SciPy、Matplotlib。在解压后的 `chapter6_latest` 目录运行：

```bash
python -m pip install -r requirements.txt
python model_assisted_lab.py
```

默认只生成 `outputs/model_assisted_comparison.png`，没有交互弹窗，不生成额外 Word 或 PDF。需要原始诊断数据时运行：

```bash
python model_assisted_lab.py --save-data
```

该选项另外保存 `pid.csv`、`nominal.csv`、`full.csv` 与 `summary.json`。图中注释和诊断指标从本次真实数据提取，未预设起动电压、起动时刻、速度跌落或误差曲线。

未知外载对照可运行：

```bash
python model_assisted_lab.py --unknown-load --save-data
```

此时被控对象仍承受相同工艺外载，两个前馈控制器接收的已知载荷及其变化率置零。未知外载结果默认写入 `outputs_unknown/`；重复运行同一场景会覆盖该目录的同名文件，也可用 `--output` 指定其他目录。

在本目录执行测试：

```bash
python -m unittest -v test_chapter6
```

需要完整数值复核时执行：

```bash
python verify_experiment.py
```

该脚本运行公式与接口测试，以及更严格 Radau 容差和未知外载的独立复算，保存 `outputs/validation.json`。它是额外验证命令，默认主入口仍只生成一张 PNG。

从项目根目录也可运行 `python -m unittest discover -s chapter6_latest -v`。本目录独立运行，不修改第五章；云环境使用现有检出目录，无需新建 Git worktree。

## 公共条件与三策略

| 条件 | 本次公开设定 |
|---|---|
| 轨迹 | 七段解析 S 型，130 mm / 1.0 s，保持至 1.2 s；速度平台 0.20 m/s |
| 控制采样 | Ts=1 ms，零阶保持；1201 个采样点、1200 个物理积分区间 |
| PID | Kp=3.8 V/cm，Ki=100 V/(cm·s)，Kd=0.02 V·s/cm，微分滤波 α=0.85；关闭积分分离 |
| 位置传感器 | 16 bit、300 mm 量程，LSB=0.00457763671875 mm |
| 速度观测 | 状态速度作为理想传感器观测，未附加噪声 |
| 执行器 | 总控制电压 ±10 V；一阶阀芯 τ=2.5 ms |
| 工艺外载 | 最大 163 kN，`[0.50,0.92) s`；20 ms 加载、30 ms 卸载余弦过渡 |
| 压力处理 | 理想压力测量后一阶滤波，历史权重 αp=0.2；供油压差保护下限 0.5 MPa |
| 完整组增益预测 | 1 ms，仅基于当前已知工艺力变化率预测孔口增益所用压力 |
| 外载预览 | 0 ms，参考计划按当前采样时刻读取 |
| 数值积分 | 每个控制周期调用隐式 Radau，默认 rtol=1e−5；压力和速度作为连续状态积分 |

三组的被控对象、初态、参考、工艺外载、传感器、采样时序及反馈 PID 参数相同。两个前馈组共享同一已知工艺计划、双腔连续性模型和阀动态逆补偿；仅孔口流量增益的压力来源不同。

| 策略 | 前馈开关 | 孔口增益 |
|---|---|---|
| `pid`：纯 PID 反馈 | 关闭 | 由反馈误差被动产生控制电压 |
| `nominal`：标称前馈 + PID | 开启 | 使用由双阀口及空载巡航力平衡计算的固定标称压力 |
| `full`：完整模型辅助 | 开启 | 使用滤波实测两腔压力，结合公开的 1 ms 工艺导数增益预测 |

所有组从约 10 mm 的同一 ADC 校准原点冷启动，速度及阀芯状态为零，两腔初压均为回油压力 0.1 MPa。初始液压力与活塞杆外端大气力相平衡，没有预先移动到参考轨迹上，也没有按期望压力初始化不同策略。

130 mm 的距离用于匹配材料图中的 0.20 m/s 巡航速度。沿用七段比例 `0.10/0.15/0.10/0.30/0.10/0.15/0.10` 时，`vmax=D/(1.0−0.35)`；原 100 mm 对应 0.153846 m/s。本次传感器为 16 bit，而非第五章的 12 bit，这是高精度课堂示例的公开条件。

## 模块三接口与物理逆模型

实际入口使用 `model_assisted_controller.py` 中的 `ModelAssistedController`，保留 Word 的 `enable_ff`、`enable_gain_sched` 开关以及 `(u_total, u_ff, u_fb)` 返回结构：

```text
update(r_state, y_meas, P_meas,
       jerk_d=规划跃度,
       known_force_n=当前已知工艺力,
       known_force_rate_n_s=该计划的当前变化率,
       origin_m=绝对位置原点)
```

`r_state=[位置m,速度m/s,加速度m/s²]`；`y_meas=[相对位移m,速度m/s]`；`P_meas=[P1,P2]`，压力单位 Pa。PID 内部将位置误差转为 cm，输出和阀死区采用 V。规划器提供位置、速度、加速度及参考跃度；未提供 `jerk_d` 时，接口使用历史标称力差分，而非测量压力或测量速度的强微分。

前馈沿用第六章式 6.1 的动力学需求，并与原 Twin 的平滑 Stribeck + 粘性摩擦模型一致：

```text
F_d = m a_d + F_friction(v_d) + F_known
F_dot_d = m j_d + (dF_friction/dv) a_d + F_dot_known
```

`F_friction` 已包含粘性阻尼，因此不重复叠加 `sigma*v_d`。将两腔连续性方程合成为液压力变化率：

```text
F_h = A1 P1 − A2 P2
F_dot_h = G(P1,P2,x) u_lin + H(P1,P2,x,v_d)
u_lin = (F_dot_d − H) / G
```

比较实际力与期望动力学力时使用扣除外端大气力后的净液压力；该大气力为常量，不改变力变化率反演。本次初始净液压力和期望动力学力均为零。

`G` 的单位为 N/(s·V)，由两阀口有向孔口流量、两腔有效体积模量及容积共同确定；`H` 的单位为 N/s，包含运动排量、内外泄漏和低压补油支路。当前滤波压力用于连续性项，标称/完整策略分别选择固定/自适应孔口增益。该反演为真实油液压缩建压提供流量，避免将“力→压力→泄漏”的近似映射误当作完整建压过程。

有量纲的流量常数由 `Cd*w*(xv_max/10)*sqrt(2/rho)` 计算，死区按 `10*deadzone` 转为 V；本次物理与补偿死区均为 0.40 V。之后执行分段死区逆映射和共同的一阶阀零阶保持逆模型：

```text
a = exp(−Ts/τ)
u_ff_requested[k] = (u_valve_target[k] − a u_valve_memory[k−1]) / (1−a)
```

前馈限幅后按可实现的阀状态更新记忆，反馈输出限幅跟随剩余总电压余量。停止段的反馈小残差也经过死区补偿，以减小内泄漏引起的持位漂移；补偿偏置单独记录，不积累进 PID 状态。

图中接近 1.0 s 停止时的短暂电压脉冲和后续持位切换保留了真实计算结果：阀目标下降经动态逆模型产生电压变化，停止段另外有 ±0.40 V 的死区补偿。电压并非全程光滑，图没有对这些瞬态进行平滑或隐藏。

起动电压由规划跃度引起的建压需求和阀动态逆模型算出，约 1.21 V 的首指令不是硬编码脉冲。所有组采用原 Twin 的平滑低速摩擦近似；起动时刻定义为实际速度首次超过 `1e−4 m/s`，不等同于严格静摩擦集合模型的粘滞解除时刻。应同时查看参考速度达到相同阈值的时刻。

## 已知工艺场景及因果边界

默认按 PPT 6.2 允许的预知工艺反力场景设置，前馈参数模型与对象匹配。两个前馈组收到相同的公共 `planned_load` 计划及其解析变化率；控制器不读取对象的真实外载字段、积分器内部导数或未来真实压力。

G/H 反演控制的是力变化率，要求起点的实际力与期望力匹配。本次冷启动的初始已知工艺力为零，两腔初压提供静止平衡，满足该条件。若初始就存在非零恒定外力，需要预建压或初始化对应力状态；当前 API 没有自动静态力误差伺服，不能据此承诺任意初态、任意恒定载荷的无误差跟踪。

完整组的 1 ms 预测仅将当前已知工艺力变化率通过面积比平衡关系换算为增益计算中的压力增量。它没有提前读取未来测量，`load_preview_s=0`，也没有引入测量压力导数强反馈。工艺外载经牛顿方程作用，腔压和速度继续由 ODE 积分，不将其直接赋成目标值。

在 `--unknown-load` 对照中，控制器只能在测量变化后通过压力自适应与 PID 响应；不能把默认已知计划的精度或“突加外载无误差”结论套用到未知扰动。

## 与原 Word 及课件的对应

`materials/module3_reference.py` 保留 Word 模块三原始参数键（如 `m`、`Ct`、`K_flow`、`P1_0`、`P2_0`），作为教学参考，不是实际仿真入口。可执行模块三保留其二自由度架构，补齐量纲、两腔连续性、方向选择、压力滤波和总电压约束。

这些修正有物理依据：原 Word 单腔运动流量加泄漏估计不能独立描述冷启动建压；负方向分支和停止段处理不完整；只使用当前期望速度/加速度会在七段零初态得到零前馈，与文字声称的起动电压冲突。本实现通过规划跃度和阀逆模型计算预建压，分别验证双腔反演、首指令来源和冷启动动态。

材料中的数字作为目标与示例对照，而非强制绘图数值：Word 写增益下降约 45%，PPT 的 16→4 MPa 压差对应 50%；Word 写全程误差小于 0.05 mm，PPT 的重载误差示例为 0.10 mm；起动 81.1 ms、1.0 ms、1.20 V 及电压 2.5→4.2 V 都必须用实际数组复核。课后 `work_6_3.py` 属于独立死区失配任务，本次范围为课堂三策略。

独立使用 `rtol=1e−6` 复算，完整组最大真实误差为 0.042308 mm，最低速度为 0.194327 m/s，跌落为 2.8365%；默认与更严格容差的完整组全轨迹最大位置差为 0.0003015 mm。数值复核支持本次已知工艺场景的精度结论。

## 原孪生与配置范围

上传的 `hydraulic_digital_twin.py` 按字节保留，原示例参数存于 `physical_config.json`。课堂配置单独记录为 `classroom_config.json`，覆盖缸行程 0.3 m、两腔初始附加容积各 0.0001 m³、有效体积模量 1.8 GPa、归一化阀死区 0.04、阀芯最大行程 0.004 m。其余摩擦等参数沿用原示例。

适配层保留原摩擦和压力相关体积模量，加入有向节流、两腔油箱补油单向阀（有效面积 0.001 m²）及外端大气力，禁用原 `x=0.4 m` 工件接触负载以免重复加载。积分结果不作压力或位移裁剪。

本次没有第四章设备测量数据，因此上述参数是公开的课堂假设而非设备辨识值。高精度结果依赖模型、已知工艺、16 bit 传感器和阀动态匹配，不能保证真实设备相同性能；模型也未包含完整管路分布、溢流阀及多相气穴。实际误差、压力及 `Kq` 变化由 ODE 得出，不人为注入振荡或指定增益下降比例。
