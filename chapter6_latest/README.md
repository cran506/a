# 第六章模型辅助复合控制

结合第六章 PPT、Word 的模块三 `ModelAssistedController` 及已有液压数字孪生，比较纯 PID、标称前馈 + PID、完整压力自适应前馈三种课堂策略。默认交付一张四联图，展示全程真实误差、总控制电压、起动速度和负载切换速度。

## 运行

需要 Python 3.10 或更高版本，依赖 NumPy、SciPy、Matplotlib。在解压后的 `chapter6_latest` 目录运行：

```bash
python -m pip install -r requirements.txt
python model_assisted_lab.py
```

默认只生成 `outputs/model_assisted_comparison.png`，没有交互弹窗，不生成额外 Word 或 PDF。需要原始诊断数据时运行：

```bash
python model_assisted_lab.py --save-data
```

该选项另外保存 `pid.csv`、`nominal.csv`、`full.csv` 与 `summary.json`。图中注释和诊断指标从本次真实数据提取，未预设起动电压、起动时刻、速度跌落或误差曲线。

未知外载对照可运行：

```bash
python model_assisted_lab.py --unknown-load --save-data
```

此时被控对象仍承受相同工艺外载，两个前馈控制器接收的已知载荷及其变化率置零。未知外载结果默认写入 `outputs_unknown/`；重复运行同一场景会覆盖该目录的同名文件，也可用 `--output` 指定其他目录。

在本目录执行测试：

```bash
python -m unittest -v test_chapter6
```

需要完整数值复核时执行：

```bash
python verify_experiment.py
```

该脚本运行公式与接口测试，以及更严格 Radau 容差和未知外载的独立复算，保存 `outputs/validation.json`。它是额外验证命令，默认主入口仍只生成一张 PNG。 默认成功要求机制、物理一致性、数值收敛及完整组已知场景的 0.05 mm/停止电压约束通过；历史参考目标另列，不把未达项隐藏为全部通过。

若需要将全部旧参考指标也作为失败条件，可运行 `python verify_experiment.py --strict-reference`。当前 5 项未达：纯 PID 首峰 0.070179 m/s 略高于旧 0.070 上限，两类前馈的速度达阈值延迟 17/18 ms 超过旧单阀 12.5 ms 及一个采样周期目标。严格模式会保存完整报告并退出失败；默认验证成功不表示这些历史目标已经满足。

从项目根目录也可运行 `python -m unittest discover -s chapter6_latest -v`。本目录独立运行，不修改第五章；云环境使用现有检出目录，无需新建 Git worktree。

三组的被控对象、含气介质、粘滑摩擦模型、初态、参考、工艺外载、传感器、采样时序及反馈 PID 参数相同。两个前馈组共享同一已知工艺计划、双腔连续性模型、阀动态逆补偿、λ=80 s⁻¹ 净液压力误差反馈、Kv=60 s⁻¹ 速度误差反馈和静止力锥持位规则；仅孔口流量增益的压力来源不同。这些辅助反馈属于两个模型辅助组共同的控制结构，纯 PID 保持材料中的位置反馈结构。

“标称前馈 + PID”和“完整模型辅助”保留材料中的策略简称，但两个模块均包含逆模型与测量压力形成的力反馈，不能称为纯开环前馈。标称组只关闭孔口增益压力调度，并未关闭共同的力反馈或连续性补偿。

| 策略 | 前馈开关 | 孔口增益 |
|---|---|---|
| `pid`：纯 PID 反馈 | 关闭 | 由反馈误差被动产生控制电压 |
| `nominal`：标称前馈 + PID | 开启 | 使用由双阀口及空载巡航力平衡计算的固定标称压力 |
| `full`：完整模型辅助 | 开启 | 使用滤波实测两腔压力，结合公开的 1 ms 工艺导数增益预测 |

所有组从约 10 mm 的同一 ADC 校准原点冷启动，速度及阀芯状态为零，两腔初压均为回油压力 0.1 MPa。初始液压力与活塞杆外端大气力相平衡，没有预先移动到参考轨迹上，也没有按期望压力初始化不同策略。

入口使用 `generate_process_scurve` 十二段工艺轨迹：八段柔和接近与加速、一段巡航、三段减速。各段以常跃度解析积分，位置、速度和加速度连续；减速及巡航时长由 130 mm 总位移和 1.0 s 终点条件求出。

这一调整首先修正参考曲线本身：原七段 130 mm/1 s 轨迹在 0.16 s 的参考速度为 0.088 m/s，而目标图的低速接近段约为 0.032 m/s，调 PID 无法改变参考轨迹。新工艺轨迹先在前 0.06 s 以 0.10 m/s² 柔和接近（最初 10 ms 连续建立加速度），再通过有界跃度连续升降加速度，使 0.16 s 的参考速度为 0.032 m/s，0.35 s 进入 0.20 m/s 巡航，1.0 s 完成 130 mm。

Word 的 `generate_scurve` 七段函数和原接口保留作参考，实际入口使用新的工艺函数并直接取得解析跃度。参考量独立于仿真输出生成，未按实测响应反向拼接曲线。本次传感器为 16 bit，而非第五章的 12 bit，这是公开的课堂条件。

## 真实静摩擦与事件积分

上传的 `hydraulic_digital_twin.py` 按字节保留。新增 `friction_model.py` 共享有向滑动摩擦函数及其单侧解析导数，`twin_adapter.py` 在继承模型上实现真正的粘住/滑动状态切换。已有 Fs、Fc、vs、σ 和全部液压、阀参数保持本次原设定；`gamma=100` 仍保存在课堂配置中，但新粘滑模型不使用 `tanh(gamma*v)`。滑动支路为：

```text
F_slip(v) = sign(v) [Fc + (Fs−Fc) exp(−(v/vs)²)] + σv
F_net = A1 P1 − A2 P2 − P_ambient (A1−A2) − F_environment − F_load
```

在静止且 `abs(F_net)<=Fs` 时，静摩擦取 `F_static=F_net`，活塞严格粘住，`x_dot=v_dot=0`。两腔压力、泄漏、补油及阀芯仍继续积分，因此控制电压能够在不移动活塞的阶段建立压力。静摩擦力是 `[-Fs,Fs]` 内的平衡量，不能用零速摩擦恒为零的平滑函数代替。

释放使用终端事件定位 `abs(F_net)=Fs+1e−6 N` 的向上穿越；若新的零阶保持外载在采样边界已超过阈值，则在该边界直接释放。`1e−6 N` 是公开的数值事件容差，不是额外整定的静摩擦幅值。滑动时固定该段方向，使用 Stribeck 分支的解析延拓供隐式求解器迭代；零速穿越由另一个终端事件精确定位。到达零速后，若净力落在静摩擦力锥内则重新粘住，否则按净力方向继续滑动或反向释放。

只有定位到真实零速事件时才将速度设为精确零，未按 1 ms 采样裁剪负速度，也未事后替换位移、速度或误差。滑动摩擦在刚释放时趋近 ±Fs，之后随速度按 `vs` 指定的指数规律演化，同时包含粘性项；没有把摩擦在释放瞬间硬切成 ±Fc。该机制在正、负两个方向相同，外载跳变也可触发释放。

CSV 记录 `friction_force_n`、`net_drive_force_n`、`sticking`、`slip_direction`、`release_pending` 及释放/重新粘住次数。配置记录中的 `friction_events` 给出采样间精确事件时间；`first_breakaway_ms` 表示真实粘滞解除，`motion_start_ms` 则是采样速度首次达到 `1e−4 m/s` 的时刻，两者分别报告。采样边界新外载可能已经越过阈值而上一积分区间仍为静止，此时 `release_pending` 为真，下一积分立即处理释放。

## 模块三接口与物理逆模型

实际入口使用 `model_assisted_controller.py` 中的 `ModelAssistedController`，保留 Word 的 `enable_ff`、`enable_gain_sched` 开关以及 `(u_total, u_ff, u_fb)` 返回结构：

```text
update(r_state, y_meas, P_meas,
       jerk_d=规划跃度,
       known_force_n=当前已知工艺力,
       known_force_rate_n_s=该计划的当前变化率,
       origin_m=绝对位置原点)
```

`r_state=[位置m,速度m/s,加速度m/s²]`；`y_meas=[相对位移m,速度m/s]`；`P_meas=[P1,P2]`，压力单位 Pa。PID 内部将位置误差转为 cm，输出和阀死区采用 V。规划器提供位置、速度、加速度及参考跃度；未提供 `jerk_d` 时，接口使用历史标称力差分，而非测量压力或测量速度的强微分。

这里采用第六章的逆动力学：由期望运动计算所需力，再结合油液压缩、泄漏和孔口压差反求阀指令。逆运动学通常处理位姿与运动变量之间的几何关系；本实验的电压还取决于力、压力与阀动态，不能仅由位置轨迹指定一个固定起动电压。

逆模型沿用第六章式 6.1 的动力学需求，并复用与被控对象一致的有向 Stribeck 滑动函数：

```text
direction = 首个非零的 v_d、a_d、j_d 的方向；全零时没有运动意图
F_plan = m a_d + F_slip(v_d, direction) + F_known
F_actual = A1 P1_filtered − A2 P2_filtered − P_ambient (A1−A2)
F_goal = F_plan + m Kv (v_d − v_measured)
F_dot_plan = m j_d + (dF_slip/dv) a_d + F_dot_known
F_dot_cmd = F_dot_plan + λ (F_goal − F_actual)
```

`F_slip` 已包含粘性阻尼，因此不重复叠加 `sigma*v_d`。在 `v_d=a_d=0` 但 `j_d>0` 的首样本，正向运动意图选择右极限 `F_slip(0,+1)=Fs=800 N`，提前提出静摩擦建压需求；未重置实际压力或阀芯，活塞仍须等真实驱动力超过阈值才释放。静止持位的参考运动量全零时不自动叠加 ±Fs。

速度误差项 `mKv(v_d−v_measured)` 是两个模型辅助组共享的因果反馈，用来抑制真实滑动后的速度偏离。它不改变被控对象的物理粘性系数 σ，也不对速度传感器作强微分。参考无运动意图且实测速度为零时，采用静止力锥目标：

```text
F_goal = F_known + clip(F_actual − F_known, −Fs, Fs)
```

该投影保留合法的静摩擦持位平衡，避免控制器强迫静止压力回到零而重新释放活塞。测量速度为零的数值判定容差是 `1e−12 m/s`；它只选择控制目标，不改写被控对象状态。目标依赖当前测量压力与已知计划，不读取真实外载字段或积分器的内部粘滑状态。

将两腔连续性方程合成为液压力变化率：

```text
F_h = A1 P1 − A2 P2
F_dot_h = G(P1,P2,x) u_lin + H(P1,P2,x,v_d)
u_lin = (F_dot_cmd − H) / G
```

比较实际力与期望动力学力时使用扣除外端大气力后的净液压力；该大气力为常量，不改变力变化率反演。本次冷启动初始净液压力为零，首个正向运动计划的摩擦需求为 800 N。

新增项 λ(F_goal−F_actual) 是因果的净液压力误差反馈，用于修正低压含气区的力跟踪与停止持位。它使用当前滤波压力，不读取真实外载或未来压力，也不是测量压力导数的强反馈。两类前馈采用相同 λ、Kv、静止力锥规则及压力滤波权重，避免将完整组改善混同于额外提高该组反馈增益。

诊断 CSV 分别记录 `planned_inverse_force_n`、`reference_friction_n`、`reference_motion_direction`、`velocity_damping_force_n`、`static_hold_force_adjustment_n`、`reference_force_n`、`measured_force_n`、`planned_force_rate_n_s` 和 `force_error_correction_n_s`；`reference_force_n` 是实际用于误差反馈的 F_goal，`force_rate_ref_n_s` 是叠加反馈后的最终力变化率需求。计划摩擦、速度反馈、静止持位调整和力反馈贡献可以分别复核。

这些力诊断字段属于模型辅助通路；纯 PID 关闭该通路时写零，不能将其误读为真实液压缸没有作用力。纯 PID 的真实净液压力可从原始 `p1_pa`、`p2_pa` 和外端大气力重新计算。

`G` 的单位为 N/(s·V)，由两阀口有向孔口流量、两腔有效体积模量及容积共同确定；`H` 的单位为 N/s，包含运动排量、内外泄漏和低压补油支路。当前滤波压力用于连续性项，标称/完整策略分别选择固定/自适应孔口增益。该反演为真实油液压缩建压提供流量，避免将“力→压力→泄漏”的近似映射误当作完整建压过程。

有量纲的流量常数由 `Cd*w*(xv_max/10)*sqrt(2/rho)` 计算，死区按 `10*deadzone` 转为 V；本次物理与补偿死区均为 0.40 V。G/H 反演先求出 `u_lin`，再由死区逆映射计算非零阀目标 `r_v`。首样本规划跃度为 `10 m/s³`，实际净液压力为零，静摩擦需求为 800 N，故 `F_dot_plan=5000 N/s`、`λ(F_goal−F_actual)=64000 N/s`，总建压力变化率需求为 `69000 N/s`。本次完整组由冷初态 G/H 反推首目标约为 `0.564599 V`，不是人为指定的起动常量。

一阶阀的零阶保持系数为 `a=exp(−Ts/τ)`。若要求零阀初态在首个采样周期末精确达到目标，硬动态逆会将首目标放大为 `r_v[0]/(1−a)`。默认启用解析初值误差相容化，允许冷启动误差的齐次分量按真实阀极点衰减：

```text
a = exp(−Ts/τ)
e_v[0] = r_v[0] − z[0]，z[0] = 0
e_v[k] = a^k e_v[0]
u_ff_requested[k] = (r_v[k] − a z[k]) / (1−a) − a e_v[k] / (1−a)
u_ff[k] = clip(u_ff_requested[k], −10, 10)
z[k+1] = a z[k] + (1−a) u_ff[k]
```

这里 `z` 是前馈通路的阀状态记忆，`e_v` 是冷启动阀初值误差分量，区别于 PID 的位置误差。首次非零目标出现时记录初值；此前的零指令等待不消耗该过程，后续换向和停止不重新触发，`reset()` 后才重新准备。未饱和的一阶模型满足 `r_v[k]−z[k+1]=e_v[k+1]`；目标恒定时，首指令直接等于该非零目标，阀状态从真实零初态自然趋近它。

前馈阀记忆始终从零开始，并使用真正输出且限幅后的 `u_ff` 更新；没有将其伪置为首目标。被控对象的实际阀状态仍由总电压 `u_total` 连同四阶液压状态积分。初值修正项随时间衰减，后续加载、减速和持位仍使用原来的动态逆模型。

`Experiment` 和 `ModelAssistedController` 默认 `enable_startup_regularization=True`。API 中设为 `False` 可恢复相同模型、初态和参考下的硬 ZOH 逆对照：

```python
from simulation import Experiment, simulate

regularized = simulate(Experiment("full"))
hard_zoh = simulate(Experiment("full_hard_zoh", enable_startup_regularization=False))
```

CSV 的 `valve_target_v`、`startup_valve_mismatch_v`、`startup_inverse_correction_v` 和实际前馈电压可复核首指令及解析修正的来源。

前馈限幅后按可实现的阀状态更新记忆，反馈输出限幅跟随剩余总电压余量。两个前馈组在运动、减速和停止阶段持续求解 G/H 连续性及内泄漏补偿，不在参考速度归零时直接关断前馈，也不再按 PID 微小候选量的符号叠加持位偏置。

精确死区逆函数在零流量两侧的极限相差 0.80 V，无法同时保持精确反演与跨零连续。当前采用公开的近零带 `abs(u_lin)<0.03 V`：在此带内，死区补偿偏置按 40 V/s 在线限速，即 1 ms 周期最多变化 0.04 V，通过物理零流量区完成过渡；显著流量时仍采用原逆映射。冷启动直接给出由逆模型计算的非零预开指令，首次阀初值误差另由上述解析项处理。

这一限制作用于真实控制指令生成链中的死区偏置，允许短暂的小流量失配，并非绘图后滤波，也不是对总电压施加 40 V/s 的硬斜率保证。停止效果需同时量测真实位置误差、残余速度和总电压 `max(abs(diff(u)))`，防止只消除电压尖峰却增加持位漂移。

本次保持上述物理参数和冷初态，由逆模型计算非零首指令，并通过有限建压跨越真实静摩擦阈值。允许阀初值误差自然衰减有起动延迟代价；电压峰值、单步回落、真实释放时间、速度达阈值时刻及跟踪精度均以本次重算的 `outputs/summary.json` 和 `outputs/validation.json` 为准，不能沿用上一版平滑摩擦结果。

## 已知工艺场景及因果边界

默认按 PPT 6.2 允许的预知工艺反力场景设置，前馈参数模型与对象匹配。两个前馈组收到相同的公共 `planned_load` 计划及其解析变化率；控制器不读取对象的真实外载字段、积分器内部导数或未来真实压力。

G/H 控制的是力变化率，本次冷启动的初始已知工艺力为零，两腔初压提供静止平衡，运动计划同时提出静摩擦建压需求。共同净液压力误差反馈能修正初始压力产生的力偏差，减少纯力导数反演对初值匹配的依赖；它不能把未告知控制器的真实外载变成已知量，也不保证任意初态、任意恒定未知载荷的无误差跟踪。

完整组的 1 ms 预测仅将当前已知工艺力变化率通过面积比平衡关系换算为增益计算中的压力增量。它没有提前读取未来测量，`load_preview_s=0`，也没有引入测量压力导数强反馈。工艺外载经牛顿方程作用，腔压和速度继续由 ODE 积分，不将其直接赋成目标值。

在 `--unknown-load` 对照中，控制器只能在测量变化后通过净液压力误差、压力增益调度与 PID 响应；不能把默认已知计划的精度或“突加外载无误差”结论套用到未知扰动。

## 与原 Word 及课件的对应

`materials/module3_reference.py` 保留 Word 模块三原始参数键（如 `m`、`Ct`、`K_flow`、`P1_0`、`P2_0`），作为教学参考，不是实际仿真入口。可执行模块三保留其二自由度架构，补齐量纲、两腔连续性、方向选择、压力滤波和总电压约束。

这些修正有物理依据：原 Word 单腔运动流量加泄漏估计不能独立描述冷启动建压；负方向分支和停止段处理不完整；只使用当前期望速度/加速度会在七段零初态得到零前馈，与文字声称的起动电压冲突。本实现用规划跃度判断首个运动方向、按 ±Fs 提出静摩擦前馈，再经双腔逆模型和阀逆模型产生有限建压过程；真实粘滞解除仍由被控对象事件决定。

材料中的数字作为目标与示例对照，而非强制绘图数值：Word 写增益下降约 45%，PPT 的 16→4 MPa 压差对应 50%；Word 写全程误差小于 0.05 mm，PPT 的重载误差示例为 0.10 mm；起动 81.1 ms、1.0 ms、1.20 V 及电压 2.5→4.2 V 都必须用实际数组复核。

PPT 的 `0.40 V死区 + 0.80 V静摩擦建压 = 1.20 V` 对应其示例参数与摩擦处理，不是四阶可压缩液压模型的普适起动电压。本次已使用真正的静摩擦集合与起动静摩擦前馈，但阀指令还受双腔容积、含气可压缩性、实际初压及力变化率控制目标影响，首值由逆动力学计算。有限建压结束后，流量仍须匹配运动和泄漏需求；不能在保留参数时将 1.20 V 强写成持续偏置。课后 `work_6_3.py` 属于独立死区失配任务，本次范围为课堂三策略。

## 原孪生与配置范围

上传的 `hydraulic_digital_twin.py` 按字节保留，原示例参数存于 `physical_config.json`。课堂配置单独记录为 `classroom_config.json`，覆盖缸行程 0.3 m、两腔初始附加容积各 0.0001 m³、油液标称体积模量 1.8 GPa、归一化阀死区 0.04、阀芯最大行程 0.004 m、粘性系数 σ=5000 N·s/m。原 Fs=800 N、Fc=500 N、vs=0.05 m/s 保留。gamma=100 仍留在课堂配置、原 gamma=500 留在原示例配置中；新的粘滑模型不使用 tanh 或 gamma，不将它们解释为当前有效摩擦平滑尺度。上传 Twin 源码不变。

`media_model.py` 新增共同的 `AeratedHydraulicModel`：回油绝对压力 Pr 下气体体积分数 α0=0.018，气体多变指数 κ=1.4。气体随压力压缩，油液与气体柔度串联：

```text
g(P) = α0 (Pr/P)^(1/κ)
α(P) = g(P) / (1−α0+g(P))
1/β_eff = (1−α(P))/β_original(P) + α(P)/(κP)
```

低压含气油具有较高柔度，高压区趋近油液模量；α0=0 时恢复原 Twin 的压力相关有效模量。该模型同时供被控对象和两个逆模型使用，是共同的教学假设，不是仅给某一策略添加的振荡曲线。分母及模量采用正值保护，记录压力和运动状态仍由 ODE 连续积分。

含气介质与真实粘滑摩擦用于所有三组。模型修正改变了起动和再粘住时刻，所有起动峰值、零速平台与 0.16 s 速度都从实际数组记录；不将这些变化强行恢复为旧 tanh 模型曲线。参数是公开课堂假设，没有设备测量辨识依据，不声称与目标图精确相等。

适配层保留原摩擦参数并使用上述事件驱动粘滑形式和共同介质模型，加入有向节流、两腔油箱补油单向阀（有效面积 0.001 m²）及外端大气力，禁用原 `x=0.4 m` 工件接触负载以免重复加载。积分结果不作压力或位移裁剪。

本次没有第四章设备测量数据，因此上述参数是公开的课堂假设而非设备辨识值。高精度结果依赖模型、已知工艺、16 bit 传感器和阀动态匹配，不能保证真实设备相同性能；模型也未包含完整管路分布、溢流阀及多相气穴。实际误差、压力及 `Kq` 变化由 ODE 得出，不人为注入振荡或指定增益下降比例。
