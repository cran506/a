# 三偏心蝶阀：论文参数参考模型

## 打开方法

- 先打开 `04_Assembly_closed.step` 查看关闭位置，SolidWorks导入选项可选择装配体。
- `01_Disc_closed.step` 为蝶板，`02_Seat_closed.step` 为简化锥面阀座。
- `03_H_axis_reference_NOT_structural_shaft.step` 为旋转轴定位圆柱，**不是实际阀杆**。它与关闭蝶板不相连，不用于强度、质量、流体阻塞或接触载荷计算。
- `开度位置` 内为15°、30°、45°、60°、75°、90°的完整位置装配，各自从关闭位置计算，不是逐次累加。
- STEP含实体、颜色和位置，不含SolidWorks原生特征树、配合、马达或仿真设置。分别打开零件后可以另存为SLDPRT；装配可另存为SLDASM。

## 论文参数与解释

依据用户提供论文节选表2-2建立；没有复制或发布上传的PDF及此前上传的CAD。

|参数|采用值|说明|
|---|---:|---|
|R0|117.5 mm|圆锥法向参考截面半径；不是蝶板外半径|
|θ|10°|圆锥半角，顶角20°|
|c|30 mm|暂解释为转轴到蝶板中面的轴向偏置|
|e|15 mm|暂解释为转轴到中面椭圆中心的径向偏置|
|α|5°|采用圆锥轴在x-y平面向-y倾斜5°的方向约定|
|B0|113.05 mm|暂解释为中面椭圆沿z方向半轴|
|A0|表值113.49 mm|精确圆锥构造得到113.495338 mm；不强制变形来拟合两项表值|
|b|15 mm|蝶板沿x厚度，截取范围x=-7.5至+7.5 mm|

坐标：x沿管道轴向，y为径向偏置方向，z平行旋转轴。蝶板中面x=0，中面椭圆中心为(0,0,0)，H轴通过(30,15,0)，方向为(0,0,1)。正开度按绕+z右手定则。

## 明确补充的几何假设

1. 使用精确圆锥与两平行平面的交集建立蝶板，而不是将117.5 mm直接作为圆盘半径。
2. 阀座内面来自同一圆锥；外半径140 mm为假设。有效密封带沿x宽度暂设2 mm，位于x=5.5至7.5 mm的大端附近。**这2 mm是轴向宽度，不是锥面母线长度，也不是论文给出的尺寸。**
3. 若把阀座沿整个蝶板15 mm厚度都设为贴合锥面，在当前偏心解释下会出现小角度刚体交叠。因此没有将该做法当作最终参考阀座；选择2 mm大端密封带仅用于建立可检查的运动参考，不能据此认定原论文采用同一结构。
4. 参考轴圆柱半径5 mm、长300 mm仅便于选轴，不是论文阀杆尺寸。未建连接轮毂、销、轴孔、轴承、填料、密封预紧和完整阀体。
5. 论文图2.2在所提供PDF中线条未完整显示，A0/B0及R0参考截面的精确对应关系不能完全核实。模型不是原始CAD的精确复原，也不是可制造产品。

## 验证

- 三个零件均为单个有效实体；导出STEP后回读检查见 `STEP回读检查.json`。
- 关闭位置蝶板与阀座交叠体积为0 mm³。
- `刚体交叠检查.csv`检查0、0.1、0.25、0.5、1、2、3、4、5、7.5、10、12.5、15、20、30、45、60、75、90°，这些样本蝶板/阀座交叠体积均为0 mm³。
- 有限角度采样不是连续运动无碰撞证明；零交叠不等于已验证密封接触压力、最小间隙、泄漏或弹性变形。参考轴不参与交叠判断。
- 预览图为45°位置，阀座仅为显示而剖切，STEP阀座仍是完整环形实体。

## 后续流场计算

这套文件提供几何起点和不同位置，**不是直接可运行的Fluent工程，也尚未形成完整流体域**。还需建立管道及实际阀体流道、补充真实轴和连接结构、进行布尔减运算、网格划分及边界条件设置。论文DN250不能简单用来替代密封圆锥截面。

计算力矩时请使用H=(30,15,0) mm及z方向；输入Fluent时按求解器长度单位转换。若几何以米导入，则力矩中心为(0.030,0.015,0) m。

## 重建

`build_model.py`用Python、CadQuery 2.6+、NumPy、Matplotlib构建实体、导出开度位置并执行检查。在脚本所在目录输出文件。全部补充假设见 `参数与坐标.json`。
