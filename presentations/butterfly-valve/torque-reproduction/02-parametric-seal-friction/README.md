# 参数化密封摩擦力矩模型：按论文式2.7–2.23实现，含明确补全解释

## 它与之前复绘脚本的区别

输入蝶阀几何与等效摩擦系数，由数值积分得到M1、M2、M3、M4，再按开启/关闭组合式合成曲线。计算中没有840.92或174.64等端点常数，也没有拟合论文曲线。

**不是已经核实与原作者程序完全相同的实现。** 所给论文节选存在符号与定义冲突，以下补全解释必须与原作者更清晰的定义核实。此程序适合参数研究与逐项核对，不应直接用于执行器最终选型。

## 使用

将 `demo_seal_friction.m`、`seal_friction_model.m` 放在同一目录，在MATLAB运行demo。MATLAB R2020a+、不需要额外工具箱。编辑demo输入区即可更换蝶阀参数。核心函数也可以单独调用：

```matlab
out = seal_friction_model(par, linspace(0,1,101));
disp(out.table);  % 压力、四项积分、开启与关闭摩擦力矩
```

只需要计算结果时，核心函数使用基础MATLAB数值积分和table，不依赖exportgraphics。

## 输入

|字段|含义|单位|
|---|---|---|
|A_mm、B_mm|蝶板中性面椭圆长、短半轴；输入半轴不是全直径|mm|
|R0_mm|密封圆锥的参考底面半径，不等于A或B|mm|
|theta_half_deg|圆锥半角；顶角19°20′时应输入(19+20/60)/2|deg|
|tilt_deg|圆锥角偏心；与摩擦方向局部角区分命名|deg|
|b_mm|蝶板轴向厚度|mm|
|c_mm|轴向偏心，沿用论文正值分支|mm|
|e_mm|径向偏心，可带符号，轴线须穿过所用椭圆内部|mm|
|mu|等效密封摩擦系数；需材料、涂层、润滑和试验依据|无量纲|
|normal_projection|式2.11中cos(alpha)的解释选择，见下|字符串|
|p_MPa|论文所指介质压力数组；未擅自等同任意试验的压差|MPa|

示例mu=0.05仅为演示假设，不是已确认的论文摩擦系数；更不是由论文端点反求的参数。A、B作为独立输入，应由自己的密封几何得到。程序不声称R0、半角等与任意输入A/B都能组成同一精确三维圆锥。

## 方程与补全解释

内部统一使用m和Pa，输出N·m。论文式2.11的N若再乘rho·dβ积分，按量纲应解释为线载荷N/m，而不是总力N。程序使用q命名以避免混淆。

1. C=sqrt(A²−B²)，h=R0*cos(theta+gamma)/sin(theta)−b/2，对应式2.15–2.16。gamma是角偏心。
2. 节选没有单独给出rho(beta)表达式。采用下焦点F1为极点的椭圆关系：rho=B²/(A−C*cos(beta))。图文把O1描述为锥顶投影且与F1分别命名，同时又用O1M定义beta，不能据此断言F1=O1。因此这是显式补全解释，**不是经确认的原作者极点定义**。
3. 在上述椭圆极坐标中，以rho*cos(theta1)=C−e分割，得到cos(theta1)=A(C−e)/[B²+C(C−e)]。这是对分割边界的几何补全，非节选明确列出的公式。
4. 式2.17–2.18按打印形式保留：K=rho*cos(beta)−A−C+h*tan(theta+gamma)，L=sqrt(K²+(R0*sin(beta))²)。特别注意保留的是R0*sin(beta)，没有擅自换成rho*sin(beta)。
5. 局部摩擦方向角命名chi(beta)，避免与角偏心gamma混用。sin(chi)=L/sqrt(h²+L²)，cos(chi)=h/sqrt(h²+L²)，对应2.19–2.20。alpha1按文字“上端T1点方向角”解释为chi(0)。
6. k1和k2按2.12–2.13积分。D=2[(sin(theta)−mu*cos(theta))*k1+2mu*cos(theta)*k2]。
7. 式2.11的cos(alpha)有两种显式选项：
   - `local`（默认）：按2.20采用cos(chi(beta))，q随beta变化；这与论文同时声称挤压力均匀的文字有冲突，因此不能称为均匀载荷模型。
   - `uniform_tilt`：把这里的cos(alpha)解释为cos(gamma)，得到常数q。这符合均匀线载荷的形式，但它是对另一处同名alpha的不同解释，也未获原作者确认。
   两个选项用于暴露符号歧义，**不是两个已经验证正确的接触模型**。默认采用local只因它直接衔接打印的2.20，并不意味着它物理上优于另一解释。
8. 用式2.7–2.10分别积分M1至M4。式2.9–2.10保留打印的局部cos(chi)因子，没有因式2.21列出cos(omega)就擅自替换。
9. Mf_open=M1+M2+M3−M4；Mf_close=M1−M2−M3+M4。出现负值保留符号并提示，不通过abs()掩盖分支/参数问题。

## 示例结果，不是论文端点复现

采用demo中几何、假设mu=0.05、local解释，在1 MPa处计算约：

- M1=466.512336 N·m；M2=314.558465 N·m。
- M3=45.094545 N·m；M4=39.530184 N·m。
- 开启=786.635161 N·m；关闭=146.389510 N·m。

这些数值不等于论文图2.6端点。本包没有校准它们；差别需从摩擦系数、极点/角度定义及载荷解释核实，不能靠更改曲线斜率消除。

## 验证范围

环境无MATLAB/Octave，**没有声称已在MATLAB实机运行**。附verify_model.py，用SciPy独立实现同样数学解释作数值验证：

- 自适应积分与每区间20001点梯形积分的四项力矩最大差约2.1e−7 N·m。
- mu=0时四项摩擦力矩为0。
- 全部长度同时放大2倍、压力和mu不变时，力矩放大8倍。
- c=0时M3=M4=0；p=0时总摩擦力矩为0。

这验证计算一致性，不验证原论文符号解释或实验准确性。模型不含预紧、夹砂、接触弹性、动水、轴承和填料摩擦；不是0–90°全行程接触仿真。当前横轴仍是压力，计算的是开启/关闭瞬间密封摩擦项。
