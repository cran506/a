# 第一步：密封面摩擦力矩，论文图2.6结果复绘

## 当前完成的范围

仅处理阀座与蝶板密封面的开启/关闭瞬间摩擦力矩，不包括轴承、填料、O形圈、静水或动水扭矩。

这一步是根据论文声明的线性关系及文字给出的端点进行结果复绘，**不是从式2.7–2.23独立计算，也不是有限元接触仿真**。来源为用户提供2.pdf的印刷页20–21。未发布上传PDF及其中图像。

## 第一轮操作

打开 `01_密封摩擦力矩_结果复绘.xlsx`，在“说明与输入”页B5修改压力（MPa）。B6、B7自动计算两项扭矩；“曲线数据”页含公式及曲线。B3、B4为文献端点推得的斜率，不是接触摩擦系数。

- Mf1 = 840.92 × p，开启瞬间密封面摩擦力矩。
- Mf2 = 174.64 × p，关闭瞬间密封面摩擦力矩。
- 此处p单位MPa、结果单位N·m；若p用Pa，系数应分别为0.00084092和0.00017464。
- p=0.45 MPa时，Mf1=378.414 N·m，Mf2=78.588 N·m。
- 横轴是介质压力，不是开度。沿用论文压力定义，不擅自改为任意工况的压差。
- 原点为零是论文忽略预紧等残余摩擦的理想化结果，不代表实际阀门零压扭矩必然为零。

## 下一步独立验算需要核实的内容

论文组合公式为 Mf1=M1+M2+M3−M4，Mf2=M1−M2−M3+M4。要独立得到M1至M4，需要核实等效摩擦系数µ_M、ρβ和θ1的几何定义、式2.15清晰表达以及局部摩擦角与角偏心使用相似符号的问题。不能用回归斜率代替摩擦系数，再宣称完成独立复现。

暂未从所给节选中找到µ_M的明确数值，因此本包未擅自取0.1或0.2，也未通过拟合端点伪造独立计算结果。此前CAD参考模型中的2 mm假设密封带没有用于本表计算。
