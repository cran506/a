## 作用力示意补充

新增图分别给出假定逆时针开启与顺时针关闭时的局部滑动方向，以及作用在蝶板上的摩擦力和法向力。Q1、Q2是为说明方向选取的潜在接触点，不代表已求解出的接触位置。速度取omega叉乘(Q-H)，投影到母线切向，滑动摩擦方向与该投影相反。箭头不代表大小。仅在保持接触且发生滑动时成立；开启后若脱离则法向力与摩擦力均为零。静摩擦不能直接使用滑动摩擦等式。绘图脚本验证摩擦方向与滑动投影相反，且与法向正交。
