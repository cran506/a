# 第五章数字 PID 三联结果图

本程序按用户所需的一张图，组合 S 型位移跟踪、真实跟踪误差和控制电压三个子图。依据为第 3、4、5 章 PPT、上传的 `HydraulicTwin`，以及 Word 中的 `DigitalPID`、`generate_scurve` 两段代码。曲线来自非线性闭环数值积分。

## 运行与输出

需要 Python 3.10 或更高版本。进入解压后的 `chapter5` 目录：

```bash
python -m pip install -r requirements.txt
python digital_pid_lab.py
```

默认只生成一张 `outputs/classroom_comparison.png`，没有交互弹窗。图的上、中两栏比较保守组与激进组，下栏增加未滤波组以展示控制电压毛刺。

需要诊断数据时执行：

```bash
python digital_pid_lab.py --save-data
```

此选项另外保存 `conservative.csv`、`aggressive.csv`、`unfiltered.csv` 和 `summary.json`。CSV 使用 SI 单位记录同步原始数据；图中位移和误差换算为 mm，电压为 V。默认运行不生成 Word、PDF 或课后实验图。

从项目根目录运行验证：

```bash
python -m unittest discover -s chapter5 -v
```

云环境使用现有检出目录，无需新建 Git worktree。

## 三组实验与时序

| 组别 | Kp / V·cm⁻¹ | Ki / V·cm⁻¹·s⁻¹ | Kd / V·s·cm⁻¹ | α |
|---|---:|---:|---:|---:|
| 保守增益，蓝线 | 3.8 | 9.0 | 0.02 | 0.85 |
| 激进增益，红色虚线 | 16.0 | 9.0 | 0.02 | 0.85 |
| 保守增益、无微分滤波，绿线 | 3.8 | 9.0 | 0.02 | 0 |

Word 提供课堂 Kp 和 α，课堂 Ki、Kd 的具体实例化值由本程序公开补充。PID 接口的位置单位为 m，内部误差换算为 cm；控制电压限幅 ±10 V 后除以 10，作为归一化阀命令。积分分离沿用 Word：误差绝对值达到 1.5 mm 时，积分增量乘 0.05，小误差恢复完整积分。

微分按 Word 的“先滤波、后增量”公式计算：

```text
D[k] = α D[k−1] + (1−α) Kd (e[k]−e[k−1]) / Ts
Δu[k] = Kp(e[k]−e[k−1]) + Ki e[k] Ts × 积分分离系数 + D[k]−D[k−1]
u[k] = clip(u[k−1] + Δu[k], −10 V, +10 V)
```

限幅后的实际电压写回下一周期的输出记忆。传感器为 12 bit、300 mm 量程，LSB 为 0.0732421875 mm。参考轨迹沿用 Word 的七段时间比例，以解析积分生成连续位置、速度和加速度；1.0 s 到达 100 mm 后保持至 1.4 s。

每 1 ms 执行一次“读取状态→ADC 量化→PID→限幅→零阶保持→Radau 积分”。时间刻度为 `t[k]=kTs`，总计 1401 个采样点、1400 个物理演化区间，诊断 CSV 包含初值和终点。

## 原模型与公开补充假设

`hydraulic_digital_twin.py` 与上传文件逐字节相同；`physical_config.json` 保存原示例参数。`classroom_config.json` 仅覆盖阀芯最大行程 `xv_max=0.0025 m`，原示例中的 `gamma=500`、`sigma=1000` 等参数保留。

闭环适配保留原模型的摩擦、压力相关有效体积模量、泄漏和端盖模型，并公开补充以下条件：

- 阀芯一阶响应时间常数为 5.3 ms，控制电压在每个采样周期内零阶保持。
- 工艺阻力最大为 180 kN，时窗为 `[0.35,0.70) s`，加载和卸载各采用 20 ms 余弦过渡，并按采样时刻锁存。原示例 `x=0.4 m` 的工件接触负载在本实验中禁用，避免重复加载。
- 两腔各接油箱补油单向阀，有效面积为 0.001 m²，仅在腔压低于回油压力时吸油。低压腔通过该物理支路补油，同时保留原模型的有效体积模量公式，积分后的压力不作裁剪。
- 孔口流量按第三章的有向压差平方根计算，允许压力差反向时回流。
- 腔压按绝对压力记录，力平衡扣除活塞杆外端的大气力 `100000 × (A1−A2) N`。初始两腔压力均为回油压力 0.1 MPa，实现静止液压力平衡。
- 初始绝对位置约为 50 mm，按 ADC 代码校准，图中位移相对该原点。

这些条件用于课堂闭环展示，未经真实设备测量辨识。第四章的参数辨识思想与时间基准对齐在实现中得到区分：没有测量数据时沿用标称参数，不能将参数选择或程序测试通过等同于模型已得到实机验证。

## 如何解读三个看点

1. **重载跟踪滞后**：外载提高驱动腔压力，缩小供油阀口压差，保守组出现约 17.6 mm 最大滞后。流量增益由实际腔压按 `Kq=Cd·w·sqrt(2(Ps−P1)/ρ)` 计算，轻、重载固定统计窗口的中位值对应约 64% 衰减；不是预设 65% 缩放。
2. **卸载后的性能权衡**：激进增益减小重载误差，但在本仿真保持窗口内出现较明显波动。应同时比较尾段误差均值、多个窗口的振幅和变化趋势，避免把偏置或仍在衰减的瞬态直接称为严格极限环。本次 1.0 s 的真实误差为保守组 +0.585 mm、激进组 −0.858 mm，因此未满足 1 s 内 0.05 mm 的定位指标；保守组在最后 0.1 s 收敛至该精度范围。
3. **量化毛刺与微分滤波**：未滤波差分对 ADC 台阶敏感，不完全微分减小高频控制变化。不同闭环组的实际轨迹可能不同；同轨迹量化残差重放提供独立的微分通道诊断，避免把组间所有电压差异都归因于量化。

图和可选 `summary.json` 中的本次计算值为正式结果。改变参数后需要重新计算与核验；本程序展示教学现象，不保证与参考图片逐像素重合，也不以人工误差曲线或附加正弦信号制造图形。

全时记录的 `kq_m2_s` 为伸出支路潜在增益；阀反向时不代表当前活动反向支路，`Ps≤P1` 时保留 NaN。对增益衰减的解释须使用有效伸出工作点。模型没有完整管路分布、溢流阀或多相气穴模型，压力极值和有限窗口响应不作为实机安全或渐近稳定性证明。
