## 三组比较与共同条件

三组共用相同初态、物理参数、采样周期和目标。两组 MPC 使用相同预测模型、时域、权重调度及输入限制，区别为是否启用 P2 上限。

| 项目 | 设置 |
|---|---|
| 目标 | 0 → 50 mm，t=0.010 s |
| 采样周期 / 时长 | 1 ms / 0.150 s |
| 预测时域 | N=20，20 ms |
| 真实执行器电压 | −10～+10 V |
| MPC 单步增量 | −4.5～+4.5 V，作为硬约束 |
| P2 实际安全线 | 21 MPa |
| 完整组预测压力界 | 20.5 MPa；QP 再内缩 0.001 MPa |
| 状态反馈 | 理想完整状态；本实验没有另加观测器或传感噪声 |

PPT 在概念说明中把增量限制列为软约束，提供的核心又以硬不等式实现。本项目按参考核心实现硬增量限制，未增加松弛变量。P2 的压力约束不作软化。

传统组使用位置式 PID，Kp=9.5 V/cm、Ki=5 V/(cm·s)、Kd=0.02 V·s/cm，α=0.85 对测量值微分。积分始终累加，只对前馈与 PID 总输出作最终硬限幅，没有抗积分饱和。前馈来自公开 50 mm 梯形运动计划：峰值速度 1.1 m/s、加减速各 10 ms，采用恒速标称双阀口流量逆；PID 的位置参考仍是 50 mm 阶跃。前馈不包含压力保护。

两组 MPC 的误差代价采用 **Q=diag([100,20,0,0,0])**（位置 mm、速度 m/s）、运动期 **W=0.01**。在同一个五状态对象上调整共同速度权重后，完整组的制动和位置超调优于仅输入约束组，且保持 P2 限压。进入 `|位置误差|≤0.5 mm` 且 `|速度|≤0.1 m/s` 的定位区后，两组共用 **W=0.1** 增量惩罚。该规则只改变优化代价，不平滑已经生成的电压或位移；逐步实际权重及模式记录在 CSV 和求解日志中。将 `settling_move_weight` 设为 `move_weight` 可复核恒定权重版本。

## 真实对象与预测模型

上传的 `hydraulic_digital_twin.py` 按字节保留，SHA256 为 `6cac5f1122be9e5f26728f0354aaa26e15836669a2496b0dc442e51301e7332f`。原参数保存在 `physical_config.json`，共同课堂覆盖在 `classroom_config.json`：行程 0.3 m、两腔死容积各 100 cm³、标称体积模量 1.8 GPa、最大阀开度 5 mm。其余质量、面积、供压、泄漏及 Fs/Fc 参数沿用原对象。阀时间常数 2.5 ms，补油面积公开设为 0.002 m²，以满足高速反向时的补油需求。这些是教学配置，未经设备辨识。

机械平衡预充初态为相对位置 0、速度 0、P1=1.05 MPa、P2=2 MPa、阀位 0；原点位于缸内 50 mm。初始净液压力为 0，内泄漏仍存在，所以不称零流量恒压平衡。真实对象保留当前的静摩擦粘滑机制：净驱动力在 ±Fs=±800 N 内时活塞严格静止，压力和阀继续积分；超过阈值后由事件求根释放。滑动时使用有向 Stribeck 分支，Fc=500 N。

公开物理状态为 `[相对位置 mm, 速度 m/s, P1 MPa, P2 MPa, 阀位等效 V]`。保留一阶阀动态后物理状态为五维，加入上一周期实际电压 `u_prev`，增广状态为**六维**。这解释了与 PPT 四物理状态、五维增广演示的维数差异。

`GreyBoxModel` 用同源孔口、体积模量、泄漏、补油及阀动态建预测 RHS，对近零摩擦、阀死区、流向和压差平方根作公开光滑近似。在线雅可比由此 RHS 求取，保留腔容积和压力对增益的影响。正则化仅属于预测模型，未改真实摩擦、真实死区或真实积分状态。尺度为压差 1 kPa、死区过渡 0.1 V、流向过渡 0.05 V、摩擦速度 0.002 m/s。

每一预测步构建含仿射项的局部模型：

```text
z_dot = Ac z + Bc u + cc
cc = f(z*,u*) − Ac z* − Bc u*
z_next = Ad z + Bd u + cd                # 含偏置的精确 ZOH
xi_next = A_aug xi + B_aug delta_u + c_aug
Xi = F xi_initial + Phi delta_U + b
```

局部离散化使用矩阵指数，避免刚性液压模态被前向 Euler 数值失稳扭曲。沿非线性名义轨迹更新各步 LTV 模型，再执行局部 QP 和候选非线性回验。位置、速度通过输出索引跟踪，历史电压不与四维参考向量直接相减。绝对压力及仿射自由响应参与约束映射。

## 约束与求解状态

QP 使用 `delta_U` 为变量，下三角求和矩阵还原绝对输入：

```text
u_sequence = u_prev + tril(ones(N,N)) delta_U
−4.5 <= delta_U <= 4.5
−10 <= u_sequence <= 10
P2_free + Phi_P2 delta_U <= 20.499 MPa    # 完整组局部 QP
```

候选非线性预测节点还需满足 P2≤20.5 MPa（数值容差 2 Pa）。原始输入与增量不等式的独立残差容差为 1e−5 V/MPa；微小数值修正后实际电压和增量严格在边界内，再对完整修正计划做非线性验证。接受最大数值修正的预算及实际修正量均记录在求解日志。

主要求解器为 OSQP，保留固定稀疏结构与热启动。状态、有限值及独立原始/对偶残差均通过才接受。若 OSQP 未通过，备用 Clarabel 解同一 QP，原失败状态保留，不重标为 OSQP 成功。非线性回验未通过时，只能使用从当前测量重新验证可行的历史移位计划；没有可信计划则明确报错，不盲目保持电压、软化压力界或裁剪压力。

完整组按用户参考核心只约束 **P2 上限**，不宣称 P1 和压力下限也已进入 QP。代码保留两腔边界的显式可配置接口；P1 峰值和最低真实绝对压力另行报告。本例压力验证仅适用于已公开的名义对象与工况，不构成对任意模型失配的安全保证。

## 结果、差异与计时

| 本次实际指标 | 前馈 + PID | 输入约束 MPC | 输入及 P2 约束 MPC |
|---|---:|---:|---:|
| 位置超调 | 15.246% | 0.963% | 0.692% |
| 最大位移 | 57.623 mm | 50.481 mm | 50.346 mm |
| 真实采样间 P2 峰值 | 23.830 MPa | 29.796 MPa | 20.638 MPa |
| 0.15 s 真实误差 | −1.097 mm | −0.015 mm | −0.017 mm |

十项机制测试及 51 项数据/严格重放检查通过。严格重放的最大位移差小于 0.0002 mm，完整组 P2 峰值仍为 20.63844 MPa。功能与数值验证通过，1 ms 实时指标未达标。

本次位移、电压、速度均为采样时刻的真实闭环状态；压力另外保留 Radau 接受节点、密输出节点及压力导数变号处的极值根。只读 1 ms 采样点可能漏掉压力尖峰；结果图和压力验收采用高密记录。全部图线不裁状态、不注入压力脉冲、不进行绘图平滑。当前数值及与 PPT 16% / 0.8% / 0.9%、24.50 / 34.06 / 21.01 MPa 的对照见 `outputs/summary.json` 和 Word 表格。

不能把 PPT 的 21.01 MPa 称为严格满足 21 MPa。本实验完整组必须通过真实采样间峰值及严格积分复算的 21 MPa 检查。位置若仍有小超调也如实记录，不写“零超调”。传统组本次在误差过零前已退饱和，超调是高速、阀动态、前馈与积分共同作用的结果；没有硬写成参考的“0.063 s 后仍正饱和”。

原孪生中的非对称面积、内泄漏和闭阀存压会使末端持位压力较高。本项目没有把它人为拉回示意图的 2 MPa。因而真实压力曲线的尾段、基线在 0.15 s 的残余误差与示意图并非逐点一致；三组比较的重点是位置超调、输入边界及实际制动压力风险。

Ts=1 ms 是**仿真采样周期**。报告分别列出 QP 求解耗时和包含线性化、多次预测、非线性验证的完整控制耗时，同时记录最大值及 ≤1 ms 比例。当前 Python 实现用于离线课堂验证，未达到 1 ms 硬实时执行要求，不能以 QP 中位数冒充完整控制步骤耗时。

## 验证与文件说明

`test_chapter7.py` 包含十项机制测试：单位/阀 ZOH、粘住建压、RHS/Jacobian、含偏置离散化、LTV 预测递推、绝对压力映射、不可行和错误雅可比拒绝、真实起动及采样间未裁剪水锤极值。`verify_experiment.py --strict` 独立核对三组 CSV 和求解记录，并将相同实际控制序列以 rtol=1e−8 重新积分；这是**记录输入的严格重放**，不混称为另一轮 MPC 闭环优化。

`outputs/<策略>.csv` 中电压作用于此刻之后的 1 ms；`valve_v` 为此刻实际阀状态。`pid_integral_v` 在 MPC 中为 NaN，表示没有该位置式积分状态。`move_weight` 与 `settling_cost_active` 记录实际优化代价。`solver_status_code` 的 0 为未启用求解/传统组，1 为已验证解，2 为已复核历史移位方案，3 为已验证但求解状态 inaccurate；备用求解器及完整细节见 JSON 日志。压力 CSV 的时刻允许相邻积分段重复，保留真实记录而非重新拟合。

退出正饱和的时刻按距 10 V 电压轨 0.0001 V 的数值容差提取，避免把 QP 的微伏级舍入当成提前制动；它不改变实际控制量。
