用户提供的 HydraulicMPC 模块二参考核心（供比对，不是完整可运行程序）

原参考的权重：Q_stage = diag([50000, 50, 0, 0, 0])，W_stage = diag([0.01])。
控制决策为每步电压增量，绝对电压为 u_prev + tril(ones(N,N)) @ U。
物理边界：|u|<=10 V，|delta_u|<=4.5 V/step，压力仅对 P2 上限约束。

原参考 _linearize_and_discretize 先调用
  Kq1, Kc1, Kq2, Kc2 = twin_model.get_jacobian_coeffs(x_curr,u_curr)
但后续固定矩阵未使用这些系数：
  Ad = [[1,1000*dt,0,0], [0,alpha_m,0,0],
        [0,0,0.85,0], [0,1.85,0,0.82]]
  Bd = [[500*dt*(1-alpha_m)*kv_eff], [(1-alpha_m)*kv_eff], [0.25], [-1.25]]

原参考扩展四状态到五状态后，构造 N*5 的预测响应，却使用 N*4 的
delta_ref_traj.flatten() 相减，维度不一致；非平衡线性化漂移项也未加入。
原贴文在 return Ad,Bd 和下一个 def 之间缺换行，不能直接复制运行。

本项目修正：
1. 保留真实阀芯动态，物理5状态+历史电压为6维增广状态。
2. 对同源灰箱非线性 RHS 求在线 Jacobian，含仿射项作精确 ZOH 离散化。
3. 通过输出索引只跟踪位置/速度；逐步构建 LTV 预测矩阵与仿射自由响应。
4. 使用同一预测轨迹重新验证候选压力，实际压力以真实混合积分轨迹验收。
5. OSQP 热启动解接受前检查状态、有限值和独立残差；保留经检查的备用
   求解器及可行历史计划路径，不将盲目保持旧电压称为安全控制。

PPT 示例 21.01 MPa 实际超过 21 MPa；本项目比较示意值但不以此宣称严格守界。
