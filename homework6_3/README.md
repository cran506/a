## 对象与共同控制条件

三策略只改变死区估计或逆映射函数，共同使用以下课堂速度通道约化模型：

```text
u_eff = D_0.5(u) = sign(u) * max(abs(u)-0.5, 0)
tau_v * dz/dt = u_eff - z
tau_m * dv/dt = K_v * z - v
```

这里的 `u_eff` 是输入死区的静态输出，`z` 是动态有效阀口的等效电压；`u_eff=0` 不代表 `z` 或流量立即归零。`input_deadzone_model.py` 对每个零阶保持输入解析积分两级动态；`deadzone_model.py` 提供阀状态在死区前的另一种顺序，用于模型回归对照。课堂约化模型不包含双腔压力状态。

参考指令为 `u_ref=5*sin(2*pi*0.1*t)` V；`v_d=K_v*u_ref`，加速度解析求导。共同参数为 `K_v=0.01 m/(s·V)`、`tau_v=0.8 ms`、`tau_m=12 ms`、`T_s=1 ms`，速度标度为 ±50 mm/s。三组主图均无测量噪声。

为在同一采样反馈环中观察估计失配的鲁棒性边界，使用公开的二级 washout 动态残差支路；其 DC 增益为零，不补偿慢变死区误差：

```text
e[k] = (vd[k]-v_meas[k])/Kv
ed = e[k-8]                         # 整个残差缓存延迟；非只延迟测量
alpha = exp(-Ts/0.002)
L1[k] = alpha*L1[k-1] + (1-alpha)*ed
h1 = ed-L1[k]
L2[k] = alpha*L2[k-1] + (1-alpha)*h1
h2 = h1-L2[k]
u_lin = (vd+tau_m*ad)/Kv + 20*h2
```

普通 PID 默认为 `Kp=Ki=Kd=0`；接口保留供扩展。`K_w=20`、`tau_w=2 ms` 和 8 个采样的完整误差缓存延迟是明确公开的压力测试假设，并非课件给定或设备辨识所得。硬符号映射的跳变本身并不证明闭环失稳；这里的反复切换来自该共同延迟反馈环。此模型也不是完整双腔逆动力学 PID。

最后三组分别计算 `u=u_lin+0.4*sign(u_lin)`、`u=u_lin+0.6*sign(u_lin)`、`u=u_lin+0.6*tanh(beta*u_lin)`，执行电压限幅 ±10 V。硬映射在 `|u_lin|<=1e-10 V` 输出零。没有为某个策略单独注入纹波、裁剪速度或对原始图线做后处理平滑。

## 计算结果

| 策略 | 有效信号零平台/ms | 近零速度平台/ms | 速度高频峰峰值/mm/s | 换向窗口符号反转 |
| --- | ---: | ---: | ---: | ---: |
| 欠补偿 0.40 V | 63.602 | 95.367 | 0.0420 | 1 |
| 硬过补偿 0.60 V | 0.831 | 14.899 | 2.6919 | 23 |
| tanh，β=18 | 27.227 | 35.374 | 0.3812 | 1 |

近零速度采用 `|v|<=0.5 mm/s`；有效信号零平台由 `|u|<=0.5 V` 的采样线性阈值重建估计。速度高频峰峰值取四阶 20 Hz 零相位高通后的窗口分量；**滤波只用于指标，不用于绘图或实际输入**。由于状态 `z` 有记忆，有效信号零平台不能混称为实际流量严格为零。由 5 V、0.1 Hz 与残余 0.10 V 静态死区直接算出的平台为约 **63.67 ms**；示意图中的 110 ms 不符合这组静态参数，不能作为本程序的实测值。

欠补偿保留明显的死区平台；硬过补偿在换向窗口出现 23 次线性指令符号切换和 2.692 mm/s 速度高频峰峰值。β=18 的光滑补偿只有一次符号切换，高频速度峰峰值降至 0.381 mm/s；它仍有可计算的残余零平台。

## β 敏感性与持续振荡检验

β=5/18/50 分别独立仿真，原始数据保存在 `outputs/beta_*.csv`。其有效信号零平台依次为 **87.302 / 27.227 / 7.135 ms**，换向窗口符号切换为 **1 / 1 / 3 次**。有限 β 时必存在正根 `q0+0.6*tanh(beta*q0)=0.5`，因此光滑并不意味着严格消除物理死区。β 增大缩短残余平台，但也提高逆映射零点斜率 `1+0.6*beta`，本实验 β=50 的高频速度峰峰值回升至 **0.806 mm/s**。

`robustness_checks.py` 另做两类补充：同种子 0.02 mm/s 测量噪声下的 β 扫描，以及从正式轨迹 5 s 的真实状态继续、保持零参考 1 s。保持前逐采样回放正式测量，恢复**完整误差缓存和两个低通记忆**；反事实仅在保持段设置 `feedback_enabled=False`，停用包括 washout 在内的全部误差反馈。

硬过补偿保持末 100 ms 的速度峰峰值为 **4.697 mm/s**，与前一个 100 ms 窗口之比为 **0.994**，符合本模型的持续小幅极限环；欠补偿和 β=18 衰减，关闭全部反馈后硬过补偿也衰减。β=50 的同类保持试验仍有 **4.652 mm/s** 峰峰值，说明更陡的连续逆映射不能保证所有闭环工况无振荡。
