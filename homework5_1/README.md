## 实验条件与微分处理

PPT 作业给定相同增益 **Kp=4.2、Ki=22.0、Kd=0.06**。继承已有代码的单位约定：接口位置为 m，内部误差为 cm；对应增益单位为 V/cm、V/(cm·s)、V·s/cm。阶跃在 **t=0.050 s** 从 0 变为 100 mm，采样周期 Ts=1 ms，运行至 1.2 s。两组均取消积分分离，输出限幅 ±10 V，12 bit ADC 量程 300 mm，LSB=0.0732421875 mm。

两组共用默认 α=0.85 的一阶不完全微分，默认采用**对测量值微分**，避免参考阶跃的微分冲击：

```text
e[k] = 100 × (r_m[k] − y_m[k])                  # cm
D[k] = α D[k−1] − (1−α) Kd (y_cm[k]−y_cm[k−1])/Ts
```

这是相同地施加于两组的工程补充，不是对教材“误差微分”阶跃公式的原样复现。若直接对误差微分，100 mm=10 cm 的阶跃首步会产生 `D=90 V`、`u_candidate=132.22 V`；增量组限幅后下一步还可能因滤波尾衰减立即反向，与参考图展示的约 42.5 V 内部峰值和正饱和起动段不同。`--derivative-mode error` 明确保留该原式及真实响应，具体数值见独立对照目录。

## 控制律与状态记忆

实验 A 为仅限最终输出的位置式 PID：

```text
I[k]      = I[k−1] + Ki e[k] Ts
u_calc[k] = Kp e[k] + I[k] + D[k]
u[k]      = clip(u_calc[k], −10, +10)
```

显式 `I` 始终累加，饱和时没有条件积分、反算或积分钳位。误差反向后，过量正积分仍可能令实际输出保持 +10 V。

实验 B 为保存限幅后实际输出的增量式 PID：

```text
Δu[k]         = Kp(e[k]−e[k−1]) + Ki e[k] Ts + D[k]−D[k−1]
u_candidate[k]= u_actual[k−1] + Δu[k]
u[k]          = clip(u_candidate[k], −10, +10)
u_prev        = u[k]                            # 写回实际输出
```

增量组没有另存一个无限累加的积分器。有界的是**迭代的实际输出记忆**；限幅前候选值可以超过 10 V，不能宣称其全部内部量均不超限。定义 `I_eff[k]=u[k]−Kp e[k]−D[k]`，可得：

```text
I_eff[k] = I_eff[k−1] + Ki e[k] Ts + (u[k]−u_candidate[k])
```

最后一项正是限幅带来的积分跟踪修正。`I_eff` 本身不必位于 ±10 V 内。若把未限幅候选值存入下一周期记忆，只裁剪送入执行器的输出，增量式同样可能积分饱和。无饱和且初值相容时，本项目两种形式严格等价。

`twin_adapter.py` 复用已有的有向节流、补油单向阀、大气修正、泄漏、压力连续性及一阶阀芯动态。每个采样周期控制输出零阶保持，先记录此刻物理状态，再计算控制并积分到下一采样点。积分方法为 Radau，默认 rtol=1e−5；没有裁剪积分后的压力或位移，没有人为添加波纹、拼接响应或平滑绘图数据。曲线上的细小波动来自量化反馈与液压动力学。

零速重启的事件函数在精确初点使用释放方向的右侧符号，防止求解器反复选中已处理的初始零根；随后的所有时刻使用真实速度。它不赋予假初速、不跳过物理时间。回归测试覆盖极短反向释放后再粘住的工况。`media_model.py` 在本作业含气率为 0 时精确恢复原 Twin 的有效模量。

## 本次结果与参考图

| 指标 | 位置式 A | 增量式 B |
|---|---:|---:|
| 超调 | 30.769% | 0.549% |
| 最大位移 | 130.769 mm | 100.549 mm |
| 限幅前候选峰值 | 43.003 V | 42.220 V |
| 真实误差过零（线性插值） | 0.204058 s | 0.644160 s |
| 首次退出 +10 V | 0.217 s | 0.055 s |
| 真实过零后退饱和迟滞 | 12.942 ms | 0 ms（已提前退出） |

位置式在过零后仍保持正饱和，随后出现明显超调；增量式在正误差仍较大时已开始退饱和，超调显著降低，与参考图教学趋势一致。参考图给出的 **31.4% / 1.0%、42.5 V、0.204 / 0.216 / 0.061 s** 是比较目标，本次数值没有强制写成这些值：A 的退出时刻晚约 1 ms；B 的退出时刻早约 6 ms，超调低约 0.451 个百分点。所有图中注释、Word 表格和摘要指标均取自当前计算结果。

“误差过零”分为真实误差线性插值时间、首个真实状态非正采样、首个 ADC 控制误差非正采样，分别记录在 `summary.json`。增量组已提前退饱和，其过零后的迟滞为 0；另有带符号的退出相对时间，不将负时间差称作负迟滞。

## 文件、数据与验证

`pid_algorithms.py` 实现两种控制律；`work_5_1.py` 负责闭环、指标与数据；`plotting.py` 绘制唯一三联图。`test_homework.py` 检查未饱和等价、积分反向、两种微分模式、量化跳变、截断记忆、复位、CSV 因果性以及静摩擦事件。`verify_results.py --strict` 独立检查 CSV 并将容差收紧至 rtol=1e−7 重新积分；`outputs/validation.json` 保存结果。参考图指标不会用作程序通过的断言。

本次 **9 项测试、30 项数据及严格复算检查全部通过**。收紧容差后的最大位移差：A 为 0.000015 mm，B 为 0.000875 mm，均远小于一个 ADC 计数；关键过零、退饱和时刻保持一致。

CSV 各列单位写在列名中。`time_s` 时刻的 `voltage_v` 作用于随后一个 Ts 周期；`valve_normalized` 是该时刻的实际阀芯状态，保留其动态滞后。`true_error_m` 用真实位移计算，`sampled_error_m` 用量化位移计算。`raw_voltage_v` 是限幅前候选量；`state_before_v` 和 `state_after_v` 是本步更新前后的实际输出记忆；`explicit_integral_v` 在 B 中为 NaN，表示没有该控制状态，而非缺失物理数据。

`package_delivery.py` 从当前数据生成 Word 报告，再写入 `manifest.json` 和完整 ZIP。清单记录各文件 SHA256，ZIP 不包含自身、Python 缓存或临时实验文件。主分支中原第五、六章文件夹与本作业互相独立。
