## 需要明确的量纲与数值差异

1. **电压换算不可省略。** 若 `Q=Cd*w*k_xv*u_eff*sqrt(2*DeltaP/rho)`，`k_xv`单位为m/V。课件第8页式子省略这个电压映射，直接商为阀芯位移m；实现时定义 `K_flow=Cd*w*k_xv*sqrt(2/rho)`，使结果确为V。上传脚本输入u为归一化，原`xv_max`为m/归一化输入；若外层输入V，要明确除以10或把参数改为m/V。
2. **死区与泄漏决定电压比例。** 若只按课件固定 `Q_req` 反演，死区0.4V、2.5V空载和增益减半意味着 `0.4+2*(2.5−0.4)=4.6V`。新提供的六步代码另把 `Q_leak` 乘 `sqrt(DeltaP/DeltaP0)`，使泄漏电压项约0.25V保持不变；同样增益减半时需 `0.4+0.25+2*1.85=4.35V`。给定重载P1=16.95MPa时精确值约4.327V，而4.20V需较低重载压力。两种公式应分别验算，不可混用。
3. **精度目标冲突。** 第六章p13和参考图为约0.10mm；用户文字明确要求<0.05mm，可作为更严格验收目标。不可把0.10mm结果改标签声称已达0.05mm。
4. **严格锁止与上传模型不同。** 上传平滑摩擦在v=0为0，且P1=P2=Pr、A1≠A2时初始净驱动力不为0，必然存在微小起步/漂移，不能严格复现80ms零位移。若升级为真正粘滑模型，应声明新增零速静摩擦集合值条件：若v=0且`abs(F_hyd−F_ext)<=Fs`，令a=0且摩擦平衡净力；超过Fs才切换动摩擦。这样1.2V仍应是选定参数/采样/泄漏下的实验突破值，不是静摩擦普适电压阈值。
5. **有限容积与压力连续性。** 压力由净流量积分建立。未知外负载在0.50s突变时，压力状态连续，随后速度/压力才变化，控制器读取测得压力后补偿。不得在被控对象里直接把P1从5改17MPa以强迫画出阶跃，不得把外载时序直接写进完整控制器生成预知电压。
6. **力前馈的实际通路。** 只用`Q=A*v + C_leak*P_req`，力要求仅通过很小泄漏项影响阀命令，不能严格实现压力动力学逆。必要时可声明加入`(V/beta)*dP_req/dt`压缩流量项、压力跟踪修正或预建压，但应区分教材最简链路和增强实现，不声称两者等价。
7. **接触事件定义。** 用户使用共同t=0.50s事件；若实际以`x>x_work`触发，三策略因跟踪不同会在不同时刻接触。共同时间外载阶跃应明确为试验台负载注入；若采用空间接触，就分别报告实际接触时刻，不悄然改时间轴。

## 建议原始数据与可核验指标

应对每个策略导出相同字段：`t,x_ref,v_ref,a_ref,x,v,P1,P2,F_ext,u,u_ff,u_fb,u_eff,Q1,Q2,Kq`。报告与图注由原始数组计算，避免写死预期数。

- 启动：定义起动为首个`v>v_threshold`且保持若干采样的时间；同时给出阈值（如0.1mm/s）及相对首个非零指令的延迟。严格静止时长需另定义位移阈值。
- 启动超调：0–0.16s中`max(v−v_ref)`及其时刻，不能直接用`max(v)`，因为参考速度本身在上升。
- 负载速度跌落：共同窗口0.50–0.62s的最小v、发生时刻、`100*(0.20−v_min)/0.20`；参考速度不恒定时使用同刻v_ref。
- 动态刚度：外载阶跃大小除以负载窗口最大增量位置偏差，并说明是有效/动态刚度指标，不是结构弹簧刚度。
- 跟踪精度：全程max|e|、负载窗口max|e|、RMSE和终值误差，单位mm；分别判断0.05mm目标。
- 控制增益：按负载前后稳定窗口均值计算Kq比及电压均值；瞬态峰值、稳态平台不要混用。
- 因果时序：记录首个负载非零采样、首个压力变化采样、首个补偿电压变化采样；保证控制器不早于传感器获得未知负载信息。
- 数值/物理检查：求解器success、压力有限且正、阀命令±10V、有效容积正，使用一个更小dt/更严容差验证关键指标收敛。
- 对照公平性：相同物理配置、初值、轨迹、PID参数；通过flags控制前馈/实时调度。若需要不同反馈增益，必须公开解释。
- 反事实检验：改变负载时刻/幅值，完整策略必须自动响应；关闭压力调度应退化；无载测试不应出现人为0.5s电压阶跃。此检验能直接发现按时间拼接的伪仿真曲线。

## 本项目的两种模型与新参考代码

本项目提供两个清楚标注的实验。四阶双腔数字孪生保留有限建压、含气柔度、阀动态及采样间粘滑事件，作为物理复核。课堂约化对象使用新提供的 `m=500 kg, Fs=3100 N, Fc=400 N, sigma=3000 N·s/m, Ct=2.7027e-9, K_flow=2.7027e-7`；`textbook_controller.py` 按新参考代码的六步因果链实现，压力在负载工作点采用准静态近似，液压流量与惯性/摩擦由连续性等效关系闭合。两种结果各自保存；不能以约化对象的压差阶跃证明四阶对象具有瞬时建压能力。

根据新给的公式，静止时 `m*a_d=100 N`、`Fs≈3100 N`、泄漏逆映射提供约 `0.80 V`，再加 `0.40 V` 死区得到首指令 `1.20 V`。巡航时 `v_d=0.20 m/s`，运动流量项约 `1.850 V`、泄漏项约 `0.250 V`，合计 `2.500 V`。当 `P1=16.95 MPa`、`Ps=21 MPa` 时，压差为 `4.05 MPa`，运动流量电压上升到约 `3.677 V`，按新公式泄漏电压仍约 `0.250 V`，故总电压约 **4.327 V**。`4.20 V` 与这组固定参数不能同时严格成立；若保持其余参数与公式，`4.20 V` 对应约 `P1=16.655 MPa`。图注与报告采用闭环实测数值。

控制器反向运动分支选有杆腔 `A2,P2` 作主动进油腔，死区补偿取负号。上传片段在最后 `np.clip` 位置混入了参数字典文字，仓库代码已整理为有效 Python 并用单元测试核对。
