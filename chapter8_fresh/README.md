## 8.1 机理模型与学习环境

四个物理状态按 SI 单位定义：`[x(m), v(m/s), P1(Pa), P2(Pa)]`。

- 两腔容积：`V1=V01+A1*x`、`V2=V02+A2*(L-x)`。
- 两腔连续性：`P1dot=beta1/V1*(Q1-A1*v-Cip*(P1-P2))`，`P2dot=beta2/V2*(Q2+A2*v+Cip*(P1-P2))`。
- 受力：`vdot=(A1*P1-A2*P2-Ffriction(v)-Fload)/mass`。
- 摩擦：上传模型的平滑 Stribeck 公式，包含静摩擦峰值、库伦摩擦和粘性项。
- 阀口：先根据电压正负确定连接拓扑，再按有向压差计算流量；电压死区为 ±0.5 V。

标称几何、摩擦、质量、供回油压力、体积模量等保留上传文件参数：`A1=.01m²、A2=.005m²、L=1m、mass=500kg、Ps=21MPa、beta=1000MPa`。原文件中 ±1 指令对应阀芯 ±5mm；本程序用 ±10V，因此阀芯增益明确除以10，原死区0.05换算为0.5V。

**与原附件的有意差别**：原来的 `sqrt(abs(dp))` 改成保留压差符号的回流公式，并在零压差附近用1kPa尺度的光滑正则化，避免非物理单向流量和导数奇异；平衡初始化也使用同一正则化方程。100mm是本实验软件安全界，原缸物理总行程仍为1m。本实验不进入0.4m工件区，因此没有把壁面碰撞力用于制造“安全停住”的图形；出现越界/非正压力就终止并报告。

物理积分以每个1ms控制周期内8个RK4子步执行，保存子步节点极值，不裁剪状态。未保护的激进指令单独使用 Radau 积分，避免在低压刚性区把显式积分失稳当成物理现象。独立测试用 Radau 对照同一事件序列下的 RK4 轨迹。

学习观测按课件五维接口保留 `[e_mm, de_mm_s, dde_mm_s2, PL_MPa, Ps_MPa]`，其中误差取“参考−实际”，`PL=P1−A2/A1*P2`。加速度由力平衡解析计算，不对位移进行二阶差分。

固定、透明的 Z-score 参数为：

```text
mean = [0, 0, 0, 0.1, 21]
std  = [5, 100, 10000, 10, 1]
```

这是手动给定的物理量纲尺度，不声称它们是在线估计后严格的经验零均值/单位方差。误差、速度、加速度采用mm单位，压力采用MPa单位。

式8.1基础奖励逐项记录：

```text
r_base = -100*e_mm² - 0.1*u_V² - (u_V-u_prev,V)²
         + 2 if |e_mm| < 0.2 else 0
```

上述括号表示仅最后的2分奖励有条件。基础奖励之外，物理失败/安全QP不可行另记终止成本−10000。优化器收到0.01倍总奖励，CSV保留未缩放的基础奖励和单列终止成本。奖励中的电压是实际安全滤波后执行电压。

课件五维接口未包含上一电压、绝对位置和两腔压力的全部信息，随机化参数也不可见，因此严格来说是部分观测的教学实现。要建立严格的全状态MDP，应增加上一动作、完整物理状态、参考轨迹，以及对隐藏参数的估计/历史编码；本程序不把五维接口的近似描述当作严格可观测性定理。

## 8.2 SAC 真正训练与熵记录

每次训练均由 SB3 新建随机策略，网络为 `5→64→64→1`，不加载既有模型，不加入教师控制损失。训练包括经验回放、双Q网络、目标网络软更新、tanh高斯采样及自动熵温度优化。

策略提议动作 `a∈[-1,1]` 对应 `u_rl=10a`。学习环境包含安全滤波，因此这是“随机提议→物理约束执行”的闭环学习。日志单列安全干预率，可判断性能有多少由策略或安全层产生；不能把高干预率下的良好轨迹全算成SAC学会了控制。

若要采用课件前50000步随机探索期，传入 `--warmup 50000`；本次十万步流程验证使用5000步预热，未声称复现完整三阶段。

训练日志每1000步记录最近1000步平均基础奖励；首个点窗口较短，终止成本另列。图(a)用对称对数纵轴保留早期大损失，没有删除早期日志或合成三阶段S形。

熵包含tanh雅可比修正：`H(u)=H(a)+ln(10)`。一维归一化动作的微分熵上界为ln2，因此课件初始2.8不能直接解释成归一化动作熵。本程序按电压熵记录；0.35仅作为可调整的目标温度条件，不强制日志达到平台。熵在当前观测下通过独立随机数上下文采样估计，记录频率不会改写训练随机数流。

非零策略熵不能单独证明产生有效颤振、消除爬行，且确定性部署均值不保留随机采样噪声。本程序不人工叠加正弦“颤振”来冒充涌现行为。

## 8.3 同一四阶对象的高阶安全滤波

行程屏障使用两侧距离，安全集与课件乘积屏障的区间含义一致：

```text
h_lower = x - (x_min + margin)
h_upper = (x_max - margin) - x
psi1 = hdot + k*h
psi2 = hddot + 2*k*hdot + k²*h
psi3 = h''' + 3*k*hddot + 3*k²*hdot + k³*h >= 0
```

取 `k=25/s`、安全内缩1.2mm。位移相对电压的有效相对阶为3；死区内部输入系数为零，不能靠除以一个假定非零增益处理。

压力一阶屏障：每个腔室同时约束 `Pdot+40*(P-P_min)>=0` 和 `-Pdot+40*(P_max-P)>=0`，范围为0.05—25MPa。25MPa是本课堂程序显式设置的压力包络，与第七章举例的21MPa额定上限不同；若沿用后者，应设置 `HOCBFFilter(p_max=21e6)` 并重新训练、验证，不应把供油压力与可允许瞬态压力无条件等同。

加加速度来自物理方程：

```text
j = (A1*P1dot - A2*P2dot - Ffriction'(v)*vdot)/mass
```

在每个阀开口方向上，压力变化率、jerk与有效阀电压呈仿射关系。将死区分成“负开口、闭口、正开口”三段，每段求 `min 0.5*(u-u_rl)²` 的标量QP（投影到可行区间），再选改动最小的解。跨越死区的整体问题是分段问题，不能直接称为单个全局凸QP。

**采样补充**：连续HOCBF约束只在控制采样时刻计算，直接零阶保持可能在强非线性区违反高阶条件。代码额外用同一ODE预测下一时刻，要求h、psi1、psi2非负，并用分段网格与求根搜索预测可行分量。该补充是非线性数值收紧，不冒充纯QP解析证明；有限网格可能遗漏很窄的分量。无解时明确抛出 `InfeasibleSafety`，不把任意饱和/零动作伪称为安全备用解。

连续时间理论还依赖正确模型、可行初始高阶集合和全时刻满足约束。当前测试只验证给定模型的离散/子步节点结果，不宣称真机、任意参数失配或故障跳变下绝对安全。跟踪评估对四种控制器统一使用同一滤波器，干预率写入指标。

## 8.4 域随机化与真机微调

每回合独立采样质量±20%、有效体积模量600—1400MPa、库伦摩擦±30%，这些参数实际进入ODE；不是仅在info字典中改变标签。参考速度固定50mm/s以避免把参考速度隐藏起来。

当前没有真实设备或真机采样数据，所以未执行真机few-shot微调，也不宣称“几秒即可消除全部未建模误差”。完整工程应先以第四章辨识数据校准分布中心，再在已验证的安全系统上采集数据并微调；未经验证的策略不可直接作为设备控制器。

## 8.6 真正的结构剪枝、定点与C部署

对两个64通道隐藏层分别保留19个完整通道：移除70.3125%的隐藏神经元，权重连接由4480降至475；这与“删除70%零散小权重”的非结构化剪枝不同。

通道重要性按独立校准轨迹上的激活RMS与下游权重范数打分。剪枝后仅用原FP32策略的pre-tanh输出，对保留的末层做岭回归校准；校准不使用理想控制电压、真实负载标签，也不使用最终5000N/0.5模量故障测试轨迹。校准轨迹覆盖600/1000/1400MPa、2500N负载，并保存全部校准观测。

仿射INT8公式实际执行：

```text
q = clip(round(r/S)+Z, -128, 127)
r_hat = S*(q-Z)
```

量化范围与零点来自真实权重和校准激活，不强制使用教材某组权重才适用的 `S=.00526,Z=-1`。层内权重和输入为INT8，居中后INT32矩阵乘和偏置累加，层间再量化。输入量化、层间重标定、末端tanh仍使用浮点，因此不是全链路无浮点策略。

导出的 `hydraulic_actor.c` 使用固定栈工作区与只读静态权重，没有malloc；输入是五个已标准化特征，输出归一化动作，乘10得到电压。源码可以用C99编译并通过测试与Python整数策略对照：

```bash
gcc -O2 -std=c99 -shared -fPIC hydraulic_actor.c -lm -o hydraulic_actor.so
```

这只是策略推理模块，没有把Python版HOCBF、传感器标定、硬件保护一起伪称为完整工业固件。模型压缩率使用实际NPZ文件字节数，包含格式元数据；推理耗时来自当前CPU的单样本NumPy测量，不能替代MCU实测或宣称0.06ms硬实时保证。若剪枝后退化，指标和图照实保留。
